# 第三章 动量守恒定律和能量守恒定律

## 3-1 质点和质点系的动量定理

### 一、冲量 质点的动量定理

**核心概念/定义**
- **冲量 $\boldsymbol{I}$**：力在时间上的累积效应，是矢量。
- **动量 $\boldsymbol{p}$**：物体质量与速度的乘积，$\boldsymbol{p} = m\boldsymbol{v}$，描述物体机械运动状态的矢量。

**定理/定律/公式**
- 恒力冲量：
  $$\boldsymbol{I} = \boldsymbol{F}\Delta t$$
- 变力冲量：
  $$\boldsymbol{I} = \int_{t_1}^{t_2} \boldsymbol{F}\,dt$$
- **质点动量定理**：质点所受合力的冲量等于其动量的增量。
  $$\int_{t_1}^{t_2} \boldsymbol{F}\,dt = \boldsymbol{p}_2 - \boldsymbol{p}_1 = m\boldsymbol{v}_2 - m\boldsymbol{v}_1$$

**适用条件/物理模型**
- 适用于质点或可视为质点的物体。
- 必须在**惯性参考系**中成立。

**典型解题套路**
- **Step 1**：明确研究对象与作用过程（初末状态、时间区间）。
- **Step 2**：规定正方向，将矢量式分解为分量式（一维直接带正负号）。
- **Step 3**：列动量定理方程 $I = \Delta p$ 求解。
- **Step 4**：碰撞/打击等极短时间过程，若平均冲力远大于重力等恒力，可忽略恒力冲量，近似认为 $\boldsymbol{I}_{\text{冲力}} \approx \Delta\boldsymbol{p}$。

---

### 二、质点系的动量定理

**核心概念/定义**
- **质点系动量**：系统内各质点动量的矢量和 $\sum\boldsymbol{p} = \sum m_i\boldsymbol{v}_i$。
- **内力**：系统内物体间的相互作用力。
- **外力**：系统外物体对系统内物体的作用力。

**定理/定律/公式**
- 质点系动量定理：合外力在时间上的冲量等于系统总动量的增量。
  $$\int_{t_1}^{t_2} \sum\boldsymbol{F}_{\text{外}}\,dt = \sum\boldsymbol{p}_2 - \sum\boldsymbol{p}_1$$

**适用条件/物理模型**
- 适用于任意质点系（刚体、流体、粒子群等）。
- **内力不改变系统总动量**，仅改变系统内部动量分配。

## 3-2 动量守恒定律

**核心概念/定义**
- **动量守恒定律**：当系统所受合外力为零时，系统的总动量保持不变。

**定理/定律/公式**
- 守恒条件：
  $$\sum\boldsymbol{F}_{\text{外}} = 0$$
- 守恒表达式：
  $$\sum\boldsymbol{p}_{\text{初}} = \sum\boldsymbol{p}_{\text{末}} = \text{恒矢量}$$
  $$m_1\boldsymbol{v}_{10} + m_2\boldsymbol{v}_{20} + \cdots = m_1\boldsymbol{v}_1 + m_2\boldsymbol{v}_2 + \cdots$$

**适用条件/物理模型**
1. **严格守恒**：系统不受外力或合外力矢量和为零。
2. **近似守恒**：外力远小于内力（如爆炸、碰撞瞬间），或作用时间极短。
3. **分量守恒**：若合外力在某方向分量为零，则该方向动量守恒（如光滑水平面，水平方向守恒）。

**典型解题套路**
- **Step 1**：划分系统——明确哪些物体构成相互作用系统。
- **Step 2**：受力分析判守恒——检查合外力是否为零或满足近似条件。
- **Step 3**：选正方向列矢量式——$\boldsymbol{p}_{\text{初}} = \boldsymbol{p}_{\text{末}}$，注意速度方向（正负号）。
- **Step 4**：联立求解——常与能量关系或运动学公式联立。

## 3-4 动能定理

### 一、功

**核心概念/定义**
- **功 $W$**：力在空间上的累积效应，是标量，单位焦耳（J）。
- **功的三要素**：作用力、力的作用点位移、力与位移的夹角。

**定理/定律/公式**
- 恒力直线运动做功：
  $$W = \boldsymbol{F}\cdot\Delta\boldsymbol{r} = F\Delta r\cos\theta$$
- 变力曲线运动做功：
  $$W = \int_{A}^{B} \boldsymbol{F}\cdot d\boldsymbol{r} = \int_{A}^{B} F\cos\theta\,ds$$
- **功率 $P$**：
  $$P = \frac{dW}{dt} = \boldsymbol{F}\cdot\boldsymbol{v}$$
  单位：瓦特（W）。

**适用条件**
- 位移 $d\boldsymbol{r}$ 必须是**力的作用点**的位移。

---

### 二、质点的动能定理

**核心概念/定义**
- **动能 $E_k$**：物体由于运动而具有的能量，$E_k = \frac{1}{2}mv^2$，标量。
- **质点动能定理**：合外力对质点所做的功等于质点动能的增量。

**定理/定律/公式**
  $$W_{\text{合}} = \int_{A}^{B} \boldsymbol{F}\cdot d\boldsymbol{r} = E_{kB} - E_{kA} = \frac{1}{2}mv_B^2 - \frac{1}{2}mv_A^2$$

**适用条件**
- 仅适用于惯性系。
- 功与动能必须针对同一质点、同一过程计算。

**典型解题套路**
- **Step 1**：明确初末状态（$v_A, v_B$）及运动路径。
- **Step 2**：逐个计算各力做功（恒力用 $Fs\cos\theta$，变力用积分或图像面积），求代数和。
- **Step 3**：列动能定理方程 $\sum W_i = \frac{1}{2}mv_2^2 - \frac{1}{2}mv_1^2$。
- **Step 4**：求解未知量——常用于已知力求位移/速度，或已知运动求力/功。

## 3-5 保守力与非保守力 势能

### 一、万有引力和弹性力做功的特点

- **共同特点**：做功仅与始末位置有关，与运动路径无关。此类力称为**保守力**。

### 二、保守力与非保守力 保守力做功的数学表达式

**核心概念/定义**
- **保守力**：沿任意闭合路径运动一周，做功为零的力。做功等于某位置函数增量的负值。
- **非保守力（耗散力）**：做功与路径有关的力（如摩擦力、空气阻力）。

**定理/定律/公式**
  $$W_{\text{保}} = \int_{\boldsymbol{r}_0}^{\boldsymbol{r}_1} \boldsymbol{F}_{\text{保}}\cdot d\boldsymbol{r} = -(E_{p1} - E_{p0}) = -\Delta E_p$$

### 三、势能

**核心概念/定义**
- **势能 $E_p$**：由物体间相对位置决定的能量，属于相互作用的**系统**共有。
- 常见势能：
  - 重力势能：$E_p = mgh$（$h$ 为相对零势能面的高度）
  - 弹性势能：$E_p = \frac{1}{2}kx^2$（$x$ 为形变量，零势点在平衡位置）
  - 万有引力势能：$E_p = -G\frac{Mm}{r}$（零势点在无穷远）

**适用条件**
- 势能零点选取是任意的，势能值具有相对性，但**势能差是绝对的**。

## 3-6 功能原理 机械能守恒定律

### 一、质点系的动能定理
  $$W_{\text{外}} + W_{\text{内}} = E_{k1} - E_{k0}$$
（内力包含保守内力 $W_{\text{保内}}$ 和非保守内力 $W_{\text{非保内}}$）

### 二、质点系的功能原理

**定理/定律/公式**
- 质点系的外力和非保守内力的总功，等于系统机械能的增量。
  $$W_{\text{外}} + W_{\text{非保内}} = (E_{k1} + E_{p1}) - (E_{k0} + E_{p0}) = E_1 - E_0$$
  其中机械能 $E = E_k + E_p$。

### 三、机械能守恒定律

**核心概念/定义**
- **机械能守恒定律**：如果外力不做功，非保守内力也不做功（即只有保守内力做功），系统的动能和势能可以相互转换，但总机械能保持不变。

**定理/定律/公式**
  $$\text{若 } W_{\text{外}} = 0 \text{ 且 } W_{\text{非保内}} = 0 \Rightarrow E_1 = E_0$$
  $$E_{k1} + E_{p1} = E_{k0} + E_{p0}$$

**适用条件/物理模型**
- 系统不受外力，或外力不做功。
- 系统内无摩擦、无耗散、无爆炸等非保守内力做功。
- 典型模型：光滑斜面滑动、理想单摆、自由落体（忽略空气阻力）、弹簧振子（无阻尼）。

**典型解题套路**
- **Step 1**：选系统——将相互作用的物体与地球/弹簧选为系统。
- **Step 2**：判守恒——检查是否只有重力或弹力做功。
- **Step 3**：定零势面——统一选取势能零点，列初末态机械能表达式。
- **Step 4**：列守恒式求解——$E_{\text{初}} = E_{\text{末}}$。常与动量守恒或运动学分解联立。

## 3-7 完全弹性碰撞 完全非弹性碰撞

**核心概念/定义**
- **碰撞**：极短时间内相互作用，运动状态急剧变化的过程。内力远大于外力，满足**动量守恒**。
- **恢复系数 $e$**：
  $$e = \frac{v_2 - v_1}{v_{10} - v_{20}}$$
  反映碰撞后分离速度与碰撞前接近速度之比。

### 1. 完全弹性碰撞（$e = 1$）

**特点**：动量守恒，**动能守恒**。

**定理/定律/公式**（一维对心碰撞）
  $$v_1 = \frac{(m_1 - m_2)v_{10} + 2m_2 v_{20}}{m_1 + m_2}, \quad v_2 = \frac{(m_2 - m_1)v_{20} + 2m_1 v_{10}}{m_1 + m_2}$$

**特例**：$m_1 = m_2$ 且 $v_{20} = 0$ → 碰后交换速度（$v_1 = 0, v_2 = v_{10}$）。

### 2. 完全非弹性碰撞（$e = 0$）

**特点**：动量守恒，碰后两物体**共速**（$v_1 = v_2 = v$），动能损失最大。

**定理/定律/公式**
  $$v = \frac{m_1 v_{10} + m_2 v_{20}}{m_1 + m_2}$$
- 动能损失：
  $$\Delta E_k = \frac{m_1 m_2(v_{10} - v_{20})^2}{2(m_1 + m_2)}$$

**典型解题套路**
- **Step 1**：列动量守恒：$m_1 v_{10} + m_2 v_{20} = m_1 v_1 + m_2 v_2$。
- **Step 2**：补充方程：
  - 弹性碰撞 → 补充动能守恒 $\frac{1}{2}m_1 v_{10}^2 + \frac{1}{2}m_2 v_{20}^2 = \frac{1}{2}m_1 v_1^2 + \frac{1}{2}m_2 v_2^2$
  - 完全非弹性碰撞 → 补充 $v_1 = v_2$
  - 一般非弹性碰撞 → 补充恢复系数 $e$ 公式
- **Step 3**：联立求解。

## 3-8 能量守恒定律

**核心概念/定义**
- **能量转换与守恒定律**：能量既不能消灭，也不能创生，只能从一个物体传递给另一个物体，或从一种形式转换为另一种形式。在转化和传递过程中，**总能量保持不变**。
- 它是物理学中最普遍、最基本的定律之一，超越机械能范畴（包含热、电、化学、核能等）。

### 一、质心

**核心概念/定义**
- **质心 $C$**：质量分布的平均位置。

**定理/定律/公式**
- 离散质点系：
  $$\boldsymbol{r}_C = \frac{\sum m_i \boldsymbol{r}_i}{\sum m_i} = \frac{\sum m_i \boldsymbol{r}_i}{M}$$
- 连续体：
  $$\boldsymbol{r}_C = \frac{1}{M}\int \boldsymbol{r}\,dm$$
- 分量式（如 $x$ 方向）：
  $$x_C = \frac{\sum m_i x_i}{M}$$

### 二、质心运动定理

**核心概念/定义**
- 质点系的总质量与质心加速度的乘积，等于作用在质点系上所有外力的矢量和。内力不影响质心运动。

**定理/定律/公式**
  $$\sum\boldsymbol{F}_{\text{外}} = M\boldsymbol{a}_C$$

**适用条件/物理模型**
- 质心的运动等同于一个位于质心、质量等于系统总质量的质点，在受到所有外力作用下的运动。
- 若 $\sum\boldsymbol{F}_{\text{外}} = 0$，则 $\boldsymbol{a}_C = 0$，质心速度恒定（质心动量守恒）。
