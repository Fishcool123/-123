# 📚 代数部分

## 一、行列式

| 公式 | ⚠️ 陷阱 |
|:-----|:------|
| 副对角线 | $\begin{vmatrix}& &a_{1n}\\&\ddots&\\a_{n1}&&\end{vmatrix}=(-1)^{\frac{n(n-1)}{2}}a_{1n}\cdots a_{n1}$ | 指数 $\frac{n(n-1)}{2}$ |
| 范德蒙德 | $\begin{vmatrix}1&\cdots&1\\x_1&\cdots&x_n\\\vdots&\ddots&\vdots\\x_1^{n-1}&\cdots&x_n^{n-1}\end{vmatrix}=\prod_{1\le j<i\le n}(x_i-x_j)$ | 大指标减小指标 |
| $|kA|$ | $\boxed{|kA|=k^n|A|}$ | 不是 $k|A|$！ |
| 分块主对角 | $\begin{vmatrix}A&O\\C&B\end{vmatrix}=\begin{vmatrix}A&C\\O&B\end{vmatrix}=|A|\cdot|B|$ | |
| 分块副对角 | $\begin{vmatrix}O&A\\B&C\end{vmatrix}=(-1)^{mn}|A|\cdot|B|$ | $A_{m\times m},B_{n\times n}$ |
| $|AB|$ | $|AB|=|A|\cdot|B|$ | $|A+B|\neq|A|+|B|$ |

## 二、矩阵与秩

| 公式 | ⚠️ 陷阱 |
|:-----|:------|
| 逆的乘积 | $\boxed{(AB)^{-1}=B^{-1}A^{-1}}$ | 顺序取反！ |
| 逆的转置 | $(A')^{-1}=(A^{-1})'$ | |
| 伴随公式 | $A^*A=AA^*=|A|E$，$A^{-1}=\frac{1}{|A|}A^*$ | |
| $|A^*|$ | $\boxed{|A^*|=|A|^{n-1}}$ | |
| $R(A^*)$ | $R(A^*)=\begin{cases}n,&R(A)=n\\1,&R(A)=n-1\\0,&R(A)<n-1\end{cases}$ | 反推：$R(A^*)=1\Rightarrow R(A)=n-1$ |
| 积的秩 | $\boxed{R(AB)\le\min\{R(A),R(B)\}}$ | |
| Sylvester | $\boxed{R(A)+R(B)-n\le R(AB)\le\min\{R(A),R(B)\}}$ | $A_{m\times n},B_{n\times p}$ |
| $AB=0$ | $\boxed{R(A)+R(B)\le n}$ | $\le$ 不是 $=$ |
| 乘可逆阵 | $R(PAQ)=R(A)$ | $P,Q$ 可逆 |

## 三、向量与线性方程组

| 公式 | ⚠️ 陷阱 |
|:-----|:------|
| 无关方阵 | $A$ 的行/列向量组无关 $\iff |A|\neq0\iff R(A)=n$ | |
| 极大无关组 | 列向量作**行**变换，首非零元列 $\to$ 极大无关组 | ⚠️ 只做行变换 |
| 向量组等价 | (I) 与 (II) 等价 $\iff R(\text{I})=R(\text{II})=R(\text{I,II})$ | |
| 正交→无关 | 非零正交向量组 $\Rightarrow$ 线性无关 | 反之不成立 |

### 线性方程组解的结构

| 情况 | 条件 | ⚠️ |
|:-----|:-----|:---|
| 非齐次无解 | $R(A)\neq R(B)$ | |
| 非齐次唯一解 | $R(A)=R(B)=n$ | |
| 非齐次无穷多解 | $R(A)=R(B)=r<n$ | |
| 齐次只有零解 | $R(A)=n$（方阵：$|A|\neq0$） | |
| 齐次有非零解 | $R(A)<n$（方阵：$|A|=0$） | |
| 解空间维数 | $\boxed{\dim N(A)=n-R(A)}$ | ⚠️ 是 $n-R(A)$ 不是 $R(A)$！ |
| 非齐次通解 | $X=\eta^*+k_1\xi_1+\cdots+k_{n-r}\xi_{n-r}$ | $\eta^*$：特解；$\xi_i$：基础解系 |
| 差为齐次解 | $\eta_1-\eta_2\in N(A)$ | |

## 四、特征值与相似对角化

| 公式 | ⚠️ 陷阱 |
|:-----|:------|
| 特征方程 | $|\lambda E-A|=0$ 或 $|A-\lambda E|=0$（差 $(-1)^n$） | |
| 迹=特征值和 | $\boxed{\sum\lambda_i=\text{tr}(A)=\sum a_{ii}}$ | |
| 行列式=特征值积 | $\boxed{\prod\lambda_i=|A|}$ | $A$ 可逆 $\iff$ 全部 $\lambda_i\neq0$ |
| $A^{-1}$ 特征值 | $\lambda^{-1}$ | |
| $A^*$ 特征值 | $|A|\lambda^{-1}$ | |
| $f(A)$ 特征值 | $f(\lambda)$ | |
| 几何重数 | $n-R(\lambda_0E-A)$ | $\le$ 代数重数 |

### 对角化与实对称阵

| 条件 | 公式/判别 |
|:-----|:---------|
| 充要条件 | 每个特征值：几何重数 = 代数重数 |
| 充分非必要 | $n$ 个特征值互异 $\Rightarrow$ 可对角化 |
| 实对称阵 | 特征值全实数；不同特征值向量**正交**；**必可正交对角化** |
| 正交对角化 | $P'AP=\text{diag}(\lambda_1,\ldots,\lambda_n)$，$P$ 为正交阵 |

> ⚠️ 不同特征值向量天然正交只需单位化！同特征值多向量才需施密特。

## 五、二次型

| 公式 | ⚠️ 陷阱 |
|:-----|:------|
| 矩阵表示 | $f=X'AX$，$A'=A$ | $a_{ij}=a_{ji}=\frac{1}{2}$(交叉项系数) |
| 正交变换 | $X=PY$，$f=\sum\lambda_i y_i^2$ | $P$ 为正交阵 |
| 秩与惯性指数 | $\boxed{R(f)=p+q}$，符号差 $s=p-q$ | |
| 正定充要 | 特征值全 $>0$；或**顺序主子式**全 $>0$ | ⚠️ 左上角！ |
| 负定充要 | 奇阶顺序主子式 $<0$，偶阶 $>0$ | |
| 半正定 | 特征值全 $\ge0$；或**所有**主子式 $\ge0$ | ⚠️ 不能只看顺序主子式！ |

## 六、线性空间与线性变换

| 公式 | ⚠️ 陷阱 |
|:-----|:------|
| 基变换 | $(\beta_1,\ldots,\beta_n)=(\alpha_1,\ldots,\alpha_n)P$ | $P$ 第 $j$ 列 = $\beta_j$ 在旧基下坐标 |
| 坐标变换 | $X=PX'$，$X'=P^{-1}X$ | ⚠️ 方向相反！ |
| 求 $P$ | $(A\mid B)\xrightarrow{\text{行}} (E\mid P)$ | |
| 线性变换矩阵 | $\mathcal{T}(\alpha_1,\ldots,\alpha_n)=(\alpha_1,\ldots,\alpha_n)A$ | $A$ 第 $j$ 列 = $\mathcal{T}(\alpha_j)$ 坐标 |
| 坐标关系 | $Y=AX$ | |
| 不同基下矩阵 | $B=P^{-1}AP$ | ⚠️ $P$ 是旧→新过渡矩阵 |
| 秩-零度定理 | $\dim V=R(\mathcal{T})+N(\mathcal{T})$ | |

## 七、向量运算

| 运算 | 公式 | ⚠️ 陷阱 |
|:-----|:-----|:------|
| 点积 | $\vec{a}\cdot\vec{b}=a_xb_x+a_yb_y+a_zb_z=|\vec{a}||\vec{b}|\cos\theta$ | 标量 |
| 叉积 | $\vec{a}\times\vec{b}=\begin{vmatrix}\vec{i}&\vec{j}&\vec{k}\\a_x&a_y&a_z\\b_x&b_y&b_z\end{vmatrix}$ | ⚠️ 反交换：$\vec{b}\times\vec{a}=-\vec{a}\times\vec{b}$ |
| 混合积 | $[\vec{a}\vec{b}\vec{c}]=(\vec{a}\times\vec{b})\cdot\vec{c}=\begin{vmatrix}a_x&a_y&a_z\\b_x&b_y&b_z\\c_x&c_y&c_z\end{vmatrix}$ | 标量 |
| 共面条件 | $[\vec{a}\vec{b}\vec{c}]=0$ | |
| 四面体体积 | $V=\frac{1}{6}|[\vec{a}\vec{b}\vec{c}]|$ | ⚠️ 系数 $\frac{1}{6}$！ |
| $\vec{a}\perp\vec{b}$ | $\vec{a}\cdot\vec{b}=0$ | |
| $\vec{a}\parallel\vec{b}$ | $\vec{a}\times\vec{b}=\vec{0}$ | |

## 八、平面与直线

### 平面方程

| 形式 | 方程 | 参数 |
|:-----|:-----|:-----|
| 点法式 | $A(x-x_0)+B(y-y_0)+C(z-z_0)=0$ | 法向量 $\vec{n}=(A,B,C)$ |
| 一般式 | $Ax+By+Cz+D=0$ | |
| 截距式 | $\frac{x}{a}+\frac{y}{b}+\frac{z}{c}=1$ | |

### 直线方程

| 形式 | 方程 | 方向向量 |
|:-----|:-----|:--------|
| 对称式 | $\frac{x-x_0}{m}=\frac{y-y_0}{n}=\frac{z-z_0}{p}$ | $\vec{s}=(m,n,p)$ |
| 参数式 | $x=x_0+mt,y=y_0+nt,z=z_0+pt$ | |
| 一般式 $\to$ 对称式 | $\vec{s}=\vec{n}_1\times\vec{n}_2$ | ⚠️ 叉积得方向向量 |
| 三点求平面 | $\vec{n}=\overrightarrow{AB}\times\overrightarrow{AC}$ | |

### 夹角与位置

| 关系 | 公式 | ⚠️ |
|:-----|:-----|:---|
| 两平面夹角 | $\cos\phi=\frac{|\vec{n}_1\cdot\vec{n}_2|}{|\vec{n}_1||\vec{n}_2|}$ | |
| 两直线夹角 | $\cos\phi=\frac{|\vec{s}_1\cdot\vec{s}_2|}{|\vec{s}_1||\vec{s}_2|}$ | |
| 直线与平面夹角 | $\boxed{\sin\phi=\frac{|\vec{s}\cdot\vec{n}|}{|\vec{s}||\vec{n}|}}$ | ⚠️ 是 $\sin$！ |
| 异面直线 | $[\vec{s}_1\ \vec{s}_2\ \overrightarrow{M_1M_2}]\neq0$ | |

### 距离公式

| 距离类型 | 公式 |
|:---------|:-----|
| 点到平面 | $d=\frac{|Ax_0+By_0+Cz_0+D|}{\sqrt{A^2+B^2+C^2}}$ |
| 点到直线 | $d=\frac{|\vec{s}\times\overrightarrow{M_0M_1}|}{|\vec{s}|}$ |
| 异面直线 | $d=\frac{|(\vec{s}_1\times\vec{s}_2)\cdot\overrightarrow{M_1M_2}|}{|\vec{s}_1\times\vec{s}_2|}$ |

### 平面束

$\lambda\pi_1+\mu\pi_2=0$；实战用 $\pi_1+k\pi_2=0$（⚠️ 漏掉 $\pi_2$ 本身！）

## 九、二次曲面

| 曲面 | 标准方程 | 符号特征 |
|:-----|:---------|:---------|
| 椭球面 | $\frac{x^2}{a^2}+\frac{y^2}{b^2}+\frac{z^2}{c^2}=1$ | 全正 + 常数项 |
| 单叶双曲面 | $\frac{x^2}{a^2}+\frac{y^2}{b^2}-\frac{z^2}{c^2}=1$ | 两正一负 + 常数项 |
| 双叶双曲面 | $\frac{x^2}{a^2}-\frac{y^2}{b^2}-\frac{z^2}{c^2}=1$ | 两负一正 + 常数项 |
| 椭圆抛物面 | $\frac{x^2}{2p}+\frac{y^2}{2q}=z\ (pq>0)$ | 两正一零，无常数 |
| 双曲抛物面 | $\frac{x^2}{2p}-\frac{y^2}{2q}=z$ | 一正一负一零，无常数 |
| 二次锥面 | $\frac{x^2}{a^2}+\frac{y^2}{b^2}-\frac{z^2}{c^2}=0$ | 两正一负，无常数 |

### 旋转曲面

绕 $z$ 轴旋转：$z$ 不变，另一变量 $\to\pm\sqrt{x^2+y^2}$

### 投影曲线

消 $z$ 得 $H(x,y)=0$ → 投影曲线：$\begin{cases}H(x,y)=0\\z=0\end{cases}$ ⚠️ 必须加 $z=0$！
