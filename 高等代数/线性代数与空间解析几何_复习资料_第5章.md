# 第五章 线性方程组

> 期末命题权重：核心计算章，直接考题占比约 20%~25%。**行变换解方程组是全章灵魂**，解的结构是证明题高频工具。

---

## 5.1 线性方程组有解的充要条件

### 核心概念/定理

设 $AX = \beta$，$A$ 为 $m \times n$ 矩阵，$B = [A \mid \beta]$ 为增广矩阵。

| 方程组类型 | 有解充要条件 | 解的情况 |
|:-----------|:------------|:---------|
| 非齐次 $AX = \beta$ | $R(A) = R(B)$ | $R(A)=R(B)=n$ → 唯一解；$=r<n$ → 无穷多解 |
| 齐次 $AX = 0$ | 恒有解（必有零解） | $R(A)=n$ → 只有零解；$R(A)<n$ → 有非零解 |

### ⚠️ 易错点与防坑指南

- 判断解的情况必须先算 $R(A)$ 和 $R(B)$，不能只看方程数与未知数个数。
- 齐次方程组 $AX=0$ 有非零解 $\iff$ 系数行列式 $D=0$（仅$n$阶方阵）。
- $m<n$ 时也可能只有零解，$m>n$ 时也可能无穷多解。

### 🔑 典型解题套路（SOP）

- Step 1：写出增广矩阵 $B = [A \mid \beta]$；
- Step 2：作初等行变换 → 行阶梯形，读出 $R(A)$ 和 $R(B)$；
- Step 3：$R(A) \neq R(B)$ → 无解；否则继续求通解。

## 5.2 齐次线性方程组解的结构

### 核心概念/定理

$AX=0$ 的解集合 $N(A)$ 是向量空间（解空间）。

### 核心公式

**解空间的维数**：$\boxed{\dim N(A) = n - R(A)}$（自由未知数个数）

**基础解系**：$N(A)$ 的一组基 $\xi_1, \xi_2, \ldots, \xi_{n-r}$（$r = R(A)$）。

**通解**：
$$\boxed{X = k_1\xi_1 + k_2\xi_2 + \cdots + k_{n-r}\xi_{n-r}\quad (k_i \in \mathbb{R})}$$

### ⚠️ 易错点与防坑指南

- 基础解系含 $n-R(A)$ 个向量，不是 $R(A)$ 个！
- $R(A)=n$ 时基础解系含 $0$ 个向量，只有零解。
- 基础解系不唯一，但向量个数相同且等价。

### 🔑 典型解题套路（SOP）

- Step 1：$A$ 作初等行变换 → 行最简形 $A_1$；
- Step 2：确定自由未知数（不含每行首非零元的列）；
- Step 3：自由未知数依次取 $(1,0,\ldots,0),\ldots,(0,0,\ldots,1)$，回代得基础解系；
- Step 4：写出齐次通解。

---

## 5.3 非齐次线性方程组解的结构

### 核心概念/定理

**解的结构定理**：非齐次通解 = 齐次通解 + 非齐次特解。

### 核心公式

$$\boxed{X = \eta^* + k_1\xi_1 + k_2\xi_2 + \cdots + k_{n-r}\xi_{n-r}}$$

$\eta^*$ 为 $AX=\beta$ 的特解；$\xi_1,\ldots,\xi_{n-r}$ 为 $AX=0$ 的基础解系。

**特解求法**：行最简形中令**所有自由未知数取 $0$** → 代入得特解。

### ⚠️ 易错点与防坑指南

- 若 $\eta_1, \eta_2$ 均为 $AX=\beta$ 的解，则 $\eta_1 - \eta_2$ 是 $AX=0$ 的解（常考证明）。
- 通解中齐次部分自由常数个数必须 $= n - R(A)$。

### 🔑 典型解题套路（SOP）

- Step 1：增广矩阵 $B$ 作行变换 → 行最简形；
- Step 2：求 $AX=0$ 的基础解系（同5.2 SOP）；
- Step 3：自由未知数全取 $0$ 代入得 $\eta^*$；
- Step 4：按 $X = \eta^* + \sum k_i\xi_i$ 写出通解。

---

## 5.4 利用初等行变换解线性方程组

### 核心概念/定理

初等行变换不改变方程组的解（只能做行变换！）。

### ⚠️ 易错点与防坑指南

- ⚠️ 解方程组**只能做行变换，不能做列变换**！
- 行变换中某行前 $n$ 个元素全 $0$ 但最后一元素非 $0$ → 直接判无解。

### 🔑 典型解题套路（SOP）

- Step 1：写出增广矩阵 $B = [A \mid \beta]$；
- Step 2：作行变换 → 行阶梯形，判断：
  - $R(A) \neq R(B)$ → 无解，停止；
  - $R(A) = R(B) = n$ → 唯一解，继续化行最简形；
  - $R(A) = R(B) = r < n$ → 无穷多解，继续化行最简形；
- Step 3：行最简形中首非零元列 = 1，且该列其余为 $0$；
- Step 4：写出解（唯一解直接读，无穷多解按5.2/5.3 SOP写通解）。

> 🔑 **含参数线性方程组讨论 SOP（期末压轴大题必考）**：
> 特征：增广矩阵 $[A\mid\beta]$ 中含有参数（如 $\lambda, a, k$）。
> - Step 1：对 $[A\mid\beta]$ 做初等行变换 → 行阶梯形。⚠️ 含参数的行尽量放下面，避免除以含参式（防参数为 0 无意义）。
> - Step 2：找关键点：阶梯形主元中含参数的表达式 = 0，解出参数**临界值**。
> - Step 3：**分类讨论**：
>   - 参数取临界值 → 代入矩阵，算 $R(A)$ 和 $R(B)$，判断无解或无穷多解；
>   - 参数不取临界值 → 通常 $R(A)=R(B)=n$，有唯一解。
> - Step 4：在无穷多解情况下，按5.2/5.3 SOP求基础解系和特解，写出通解。

## 📋 第五章速查：核心公式汇总

| 类别 | 公式 |
|:-----|:-----|
| 非齐次有解 | $R(A) = R(B)$ |
| 唯一解 | $R(A) = R(B) = n$ |
| 无穷多解 | $R(A) = R(B) = r < n$ |
| 齐次有非零解 | $R(A) < n$（方阵：$|A| = 0$） |
| 解空间维数 | $\dim N(A) = n - R(A)$ |
| 齐次通解 | $X = \sum_{i=1}^{n-r} k_i\xi_i$ |
| 非齐次通解 | $X = \eta^* + \sum_{i=1}^{n-r} k_i\xi_i$ |
| 两非齐次解之差 | $\eta_1 - \eta_2 \in N(A)$ |
