## *2-5 非惯性系 惯性力

### 一、惯性参考系与非惯性系

**核心概念/定义**
- **惯性参考系**：牛顿定律成立的参考系。以地球为参考系研究一般宏观物体运动时，牛顿定律近似成立。
- **非惯性系**：牛顿定律不成立的参考系（存在相对加速度或旋转）。

**判定原则**
- 一个参考系是否为惯性系，一般要由**实验和观察**的结果来判定。

---

### 二、平动非惯性系中的惯性力

**核心概念/定义**
- **惯性力 $\boldsymbol{F}_i$**：在非惯性系中为使牛顿定律形式上成立而引入的**虚拟力**。不是物体间的相互作用力，没有施力物体，也不存在反作用力。

**定理/定律/公式**
- 惯性力定义：
  $$\boldsymbol{F}_i = -m\boldsymbol{a}_0$$
  （$m$ 为物体质量，$\boldsymbol{a}_0$ 为非惯性系相对惯性系的加速度）
- 大小：$F_i = ma_0$
- 方向：与 $\boldsymbol{a}_0$ **相反**
- 平动非惯性系中的动力学方程：
  $$\sum\boldsymbol{F}_{\text{真实}} + \boldsymbol{F}_i = m\boldsymbol{a}'$$
  （$\boldsymbol{a}'$ 为物体相对非惯性系的加速度）

**⚠️ 注意**
- 惯性力是虚拟力，无法用"作用力与反作用力"规律分析。它仅是坐标变换的产物，但引入后可以在非惯性系中形式地使用牛顿第二定律。

---

### 三、转动非惯性系中的惯性力

| 类型 | 公式 | 方向 | 出现条件 |
|:---|:---|:---|:---|
| **离心惯性力** | $\boldsymbol{F}_e = m\omega^2\boldsymbol{r}$ | 沿径向向外 | 参考系转动即存在 |
| **科里奥利力** | $\boldsymbol{F}_c = -2m\boldsymbol{\omega} \times \boldsymbol{v}'$ | 垂直于 $\boldsymbol{\omega}$ 和 $\boldsymbol{v}'$ 构成的平面 | 物体相对转动参考系有速度 $\boldsymbol{v}'$ 时才出现 |

**转动非惯性系动力学方程**：
$$\sum\boldsymbol{F}_{\text{真实}} + \boldsymbol{F}_e + \boldsymbol{F}_c = m\boldsymbol{a}'$$

**物理意义与实例**
- **离心力**：解释旋转圆盘上物体"被甩出"的现象。
- **科里奥利力**：地球自转偏向力——北半球运动物体向右偏，南半球向左偏（影响气旋方向、河流冲刷）。傅科摆摆动平面缓慢旋转，直观证明地球自转。

## *3-3 系统内质量移动问题

**核心概念/定义**
- **变质量系统**：系统在运动过程中不断有质量流入或流出（如落链问题、火箭喷射、雨滴下落）。

**定理/定律/公式**
- 变质量物体的动力学方程（密歇尔斯基方程）：
  $$m\frac{d\boldsymbol{v}}{dt} = \boldsymbol{F}_{\text{外}} + \boldsymbol{u}\frac{dm}{dt}$$
  （$\boldsymbol{u}$ 为进入（或离出）物体部分的相对速度，$\frac{dm}{dt}$ 为质量变化率）

**典型物理模型**
1. **落链问题**：均质链条自桌边自由下落，桌面部分受到约束力与重力的共同作用。
2. **火箭运动**：燃料喷射产生推力，$m\frac{dv}{dt} = -u\frac{dm}{dt}$（$u$ 为喷射燃气相对火箭的速度）。
   - 积分得齐奥尔科夫斯基公式：$v - v_0 = u\ln\frac{m_0}{m}$

**🔑 典型解题套路**
- **Step 1**：确定系统边界，明确质量变化方式（流入/流出）。
- **Step 2**：写出质量变化率 $\frac{dm}{dt}$ 及相对速度 $\boldsymbol{u}$。
- **Step 3**：列出动量定理或变质量动力学方程。
- **Step 4**：联立求解加速度或速度。

## *3-6 四、宇宙速度

### 一、第一宇宙速度（环绕速度）

**核心概念/定义**
- 物体在地面附近绕地球做匀速圆周运动的最小发射速度。

**定理/定律/公式**
- 万有引力提供向心力：
  $$G\frac{Mm}{R^2} = m\frac{v_1^2}{R}$$
  $$v_1 = \sqrt{\frac{GM}{R}} \approx 7.9\ \text{km/s}$$

### 二、第二宇宙速度（脱离速度）

**核心概念/定义**
- 物体挣脱地球引力束缚飞向星际空间的最小发射速度。

**定理/定律/公式**
- 机械能守恒：动能恰好抵消引力势能：
  $$\frac{1}{2}mv_2^2 = G\frac{Mm}{R}$$
  $$v_2 = \sqrt{\frac{2GM}{R}} = \sqrt{2}v_1 \approx 11.2\ \text{km/s}$$

### 三、第三宇宙速度（逃逸速度）

**核心概念/定义**
- 物体挣脱太阳引力束缚飞出太阳系的最小发射速度。

**定理/定律/公式**
- 先克服地球引力，剩余动能再克服太阳引力：
  $$v_3 \approx 16.7\ \text{km/s}$$


## *3-10 对称性与守恒律

**核心概念/定义**
- **诺特定理**：自然界中每一种连续对称性（不变性）都对应一个守恒律。

| 对称性 | 对应的守恒律 |
|:---|:---|
| **时间平移对称性** | 能量守恒 |
| **空间平移对称性** | 动量守恒 |
| **空间转动对称性** | 角动量守恒 |
| **空间反演对称性** | 宇称守恒（弱相互作用中不成立） |

**物理意义**
- 对称性是物理学最基本的原理。寻找物理规律的对称性，是现代理论物理的核心方法之一。

## *4-5 刚体的平面平行运动

**核心概念/定义**
- **平面平行运动**：刚体上各点均限制在某一固定平面的平行平面内运动。可以分解为：**质心平动 + 绕质心的定轴转动**。

**定理/定律/公式**
- 质心平动方程：
  $$\sum\boldsymbol{F} = M\boldsymbol{a}_C$$
- 绕质心转动方程：
  $$\sum M_C = J_C\beta$$
- 运动学约束（纯滚动条件）：
  $$v_C = R\omega,\quad a_C = R\beta$$

**🔑 常见刚体纯滚动斜坡加速度**
- 均质圆环/薄圆筒：$a_C = \frac{1}{2}g\sin\theta$
- 均质圆盘/圆柱：$a_C = \frac{2}{3}g\sin\theta$
- 均质球体：$a_C = \frac{5}{7}g\sin\theta$
- 推论：转动惯量越大，加速度越小，下滑越慢。


## *4-6 刚体的进动

**核心概念/定义**
- **进动**：高速自转的刚体（如陀螺）在重力矩作用下，自转轴绕竖直轴缓慢转动的现象。

**定理/定律/公式**
- 合外力矩垂直于角动量方向：
  $$\boldsymbol{M} = \frac{d\boldsymbol{L}}{dt}$$
- 角动量矢量末端做圆周运动，进动角速度：
  $$\Omega = \frac{M}{L\sin\theta} = \frac{mgr}{J\omega}$$
  （陀螺质量 $m$，质心到支点距离 $r$，自转角速度 $\omega$）

**物理意义**
- 进动是角动量定理的直接体现：力矩不改变角动量大小，只改变其方向。


## *4-7 流体 伯努利方程

`[注：此节若考纲不要求详细计算，掌握核心概念与方程形式即可]`

### 一、理想流体模型

**核心概念/定义**
- **理想流体**：绝对不可压缩（密度 $\rho$ 恒定）且无黏滞性（无内摩擦）的流体。
- **定常流动**：流体中任一点的流速、压强、密度等不随时间变化。

### 二、连续性方程
- 对不可压缩流体：
  $$S_1 v_1 = S_2 v_2 = \text{常量}$$
  （截面积越小，流速越大）

### 三、伯努利方程
- 沿同一流线：
  $$p + \frac{1}{2}\rho v^2 + \rho gh = \text{常量}$$
- 应用：流速大的地方压强小（文丘里管、飞机升力原理）。


## *4-8 万有引力的牛顿命题

**核心概念/定义**
- 牛顿使用其运动定律和万有引力定律，从理论上推导了开普勒三大定律。

**定理/定律/公式**
1. 开普勒第一定律（椭圆轨道定律）→ 从引力平方反比律可导出轨道为圆锥曲线。
2. 开普勒第二定律（面积速度守恒）→ 由角动量守恒直接推出。
3. 开普勒第三定律（$T^2 \propto a^3$）→ 从 $G\frac{Mm}{r^2} = m\frac{4\pi^2}{T^2}r$ 可导出。

**题外话**：牛顿通过证明均匀球体对外部的引力等效于质量集中于球心的质点，为天体力学奠定了基础。

**核心概念/定义**

## *5-4 密立根测定电子电荷的实验

**核心概念/定义**
- **密立根油滴实验**：通过观测带电油滴在电场和重力场中的平衡与运动，精确测定电子电荷 $e$ 的大小。

**定理/定律/公式**
- 平衡法：调节电场使油滴静止：
  $$qE = mg \Rightarrow q = \frac{mg}{E}$$
- 测量多个油滴的带电量，发现 $q$ 总是某个最小值的整数倍：
  $$q = ne,\quad n = \pm1,\pm2,\cdots$$
- 实验结果：$e \approx 1.602 \times 10^{-19}\ \text{C}$
- **意义**：首次直接证明了**电荷量子化**。


## *5-8 静电场中的电偶极子

**核心概念/定义**
- 电偶极子在非均匀电场中除受力矩外，还受到一个净力，方向指向电场增强的方向。

**定理/定律/公式**
- 在非均匀电场中的受力：
  $$\boldsymbol{F} = (\boldsymbol{p}\cdot\nabla)\boldsymbol{E} = p_x\frac{\partial\boldsymbol{E}}{\partial x} + p_y\frac{\partial\boldsymbol{E}}{\partial y} + p_z\frac{\partial\boldsymbol{E}}{\partial z}$$
- 典型现象：
  - 带电棒吸引微小纸屑（感应电偶极子受非均匀电场力）。
  - 介电泳（dielectrophoresis）：利用非均匀电场操控微小颗粒。

## *6-6 电容器的充放电

### 一、RC 电路的充电过程

**定理/定律/公式**
- 电路方程：$\mathcal{E} = \frac{q}{C} + IR = \frac{q}{C} + R\frac{dq}{dt}$
- 电荷增长规律：
  $$q(t) = C\mathcal{E}\left(1 - e^{-\frac{t}{RC}}\right) = Q_0\left(1 - e^{-\frac{t}{\tau}}\right)$$
- 时间常数：$\tau = RC$
- 电流衰减：$I(t) = \frac{\mathcal{E}}{R}e^{-\frac{t}{\tau}}$

### 二、RC 电路的放电过程

**定理/定律/公式**
- 电荷衰减：$q(t) = Q_0 e^{-\frac{t}{\tau}}$
- 电流：$I(t) = -\frac{Q_0}{\tau}e^{-\frac{t}{\tau}}$

**物理意义**
- 经过 $t = \tau$：电荷变化 $63.2\%$
- 经过 $t = 5\tau$：可认为充放电基本完成（$99.3\%$）

## *7-1 二、电流的连续性方程 恒定电流条件

**核心概念/定义**
- **电流的连续性方程**：电荷守恒定律在电流场中的表达式。

**定理/定律/公式**
- 一般形式：
  $$\oint_S \boldsymbol{j}\cdot d\boldsymbol{S} = -\frac{dq_{\text{内}}}{dt}$$
  流出闭合面的总电流等于面内电荷的减少率。
- **恒定电流条件**：
  $$\oint_S \boldsymbol{j}\cdot d\boldsymbol{S} = 0$$
  恒定电流场中，任意闭合面流出的净电流为零——即流入等于流出。


## *7-1 三、欧姆定律的微分形式

**定理/定律/公式**
- 欧姆定律的微分形式：
  $$\boldsymbol{j} = \sigma\boldsymbol{E}$$
  （$\sigma$ 为电导率，单位 $\text{S/m}$）
- 电阻率 $\rho = 1/\sigma$，则 $\boldsymbol{E} = \rho\boldsymbol{j}$

**物理意义**
- 微分形式是逐点成立的局域关系，比积分形式 $U = IR$ 更基本，适用于非均匀导体。

## *8-2 三、电子感应加速器

**核心概念/定义**
- 利用变化磁场产生的感生电场来加速电子的装置，是**感生电场存在**的重要实验验证。

**工作原理**
1. 交变励磁电流产生变化磁场 $B(t)$，感生电场线为同心圆。
2. 电子在圆形真空室中受感生电场加速：$F = eE_k = m\frac{dv}{dt}$。
3. 同时洛伦兹力提供向心力：$evB = m\frac{v^2}{R}$。
4. **轨道稳定条件**：轨道处 $B = \frac{1}{2}B_{\text{平均}}$，保持电子轨道半径不变。

## *8-4 RL 电路

### 一、RL 电路的接通（电流增长过程）

**定理/定律/公式**
- 电路方程：$\mathcal{E} = L\frac{dI}{dt} + IR$
- 时间常数：$\tau = \frac{L}{R}$
- 电流增长规律：
  $$I(t) = \frac{\mathcal{E}}{R}\left(1 - e^{-\frac{t}{\tau}}\right) = I_0\left(1 - e^{-\frac{t}{\tau}}\right)$$
- 自感电动势：$\varepsilon_L = -\mathcal{E}e^{-\frac{t}{\tau}}$

**物理过程**
- $t = 0$：$I = 0$，电感相当于**断路**。
- $t = \tau$：$I = 0.632I_0$。
- $t \approx 5\tau$：稳态，电感相当于短路导线。

### 二、RL 电路的短接（电流衰减过程）

**定理/定律/公式**
- 电流衰减：$I(t) = I_0 e^{-\frac{t}{\tau}}$
- 自感电动势：$\varepsilon_L = I_0 R e^{-\frac{t}{\tau}}$

**⚠️ 注意**：断电瞬间 $\frac{dI}{dt}$ 极大，自感电动势可远高于原电源电动势，可能击穿开关。大电感电路常用续流二极管保护。

### 三、磁场能量与 RL 电路的关系
- 电源供能 = 焦耳热 + 磁场储能：
  $$\int_0^{t_0} \mathcal{E}I\,dt = \int_0^{t_0} I^2R\,dt + \frac{1}{2}LI_0^2$$
