# 第四章 刚体转动和流体运动

## 4-1 刚体的定轴转动

### 一、刚体定轴转动的角速度和角加速度

**核心概念/定义**
- **刚体**：运动时形状和大小始终保持不变的物体（形变可忽略的理想模型）。
- **定轴转动**：刚体上所有质元绕同一条固定直线（转轴）做圆周运动。
- 定轴转动时，各质元在同一时间内具有相同的角位移、角速度和角加速度。
- 角量可用**带正负号的代数量**表示：由转轴正向俯视，**逆时针为正，顺时针为负**。

**定理/定律/公式**
- 角速度：
  $$\omega = \frac{d\theta}{dt}$$
- 角加速度：
  $$\beta = \frac{d\omega}{dt} = \frac{d^2\theta}{dt^2}$$

---

### 二、匀变速转动公式

**适用条件**：角加速度 $\beta$ 为恒量。

**定理/定律/公式**（与匀变速直线运动形式完全对应）
  $$\omega = \omega_0 + \beta t$$
  $$\theta = \theta_0 + \omega_0 t + \frac{1}{2}\beta t^2$$
  $$\omega^2 = \omega_0^2 + 2\beta(\theta - \theta_0)$$

---

### 三、角量与线量的关系

**核心概念/定义**
- 刚体上任一质元做圆周运动，其线量与整体角量通过该质元到转轴的距离 $r$ 关联。

**定理/定律/公式**
| 线量 | 角量 | 关系式 |
|:---|:---|:---|
| 弧长 $\Delta s$ | 角位移 $\Delta\theta$ | $\Delta s = r\Delta\theta$ |
| 速率 $v$ | 角速度 $\omega$ | $v = r\omega$ |
| 切向加速度 $a_\tau$ | 角加速度 $\beta$ | $a_\tau = r\beta$ |
| 法向加速度 $a_n$ | 角速度 $\omega$ | $a_n = r\omega^2$ |

## 4-2 力矩 转动定律 转动惯量

### 一、力矩

**核心概念/定义**
- **力矩 $\boldsymbol{M}$**：描述外力对刚体定轴转动改变作用的物理量。力矩是改变刚体转动状态的原因。
- **力臂 $d$**：力的作用线到转轴的垂直距离。

**定理/定律/公式**
- 矢量定义：
  $$\boldsymbol{M} = \boldsymbol{r} \times \boldsymbol{F}$$
- 大小：
  $$M = rF\sin\theta = Fd$$
- 方向判定：**右手螺旋法则**。定轴转动中，使刚体逆时针转动的力矩为**正**，顺时针为**负**。
- 合外力矩：多个共面外力对同一转轴的合外力矩等于各外力矩的**代数和**。
- 单位：$\text{N}\cdot\text{m}$

**适用条件**
- 当力的方向平行于转轴，或力的作用线与转轴相交（力臂为零）时，力矩为零，不改变转动状态。

---

### 二、转动定律

**核心概念/定义**
- **转动定律**：刚体定轴转动时，角加速度与所受合外力矩成正比，与转动惯量成反比。是解决刚体定轴转动问题的基本动力学方程。

**定理/定律/公式**
  $$M = J\beta$$
（$M$ 为合外力矩，$J$ 为转动惯量，$\beta$ 为角加速度）

**适用条件/物理模型**
- 仅适用于**刚体**的**定轴转动**。
- 所有物理量必须对**同一固定转轴**计算。

---

### 三、转动惯量

**核心概念/定义**
- **转动惯量 $J$**：量度刚体转动惯性大小的物理量，相当于平动中的质量。与刚体总质量、质量分布及转轴位置有关。

**定理/定律/公式**
- 离散质量分布：
  $$J = \sum_{i} \Delta m_i r_i^2$$
- 连续质量分布：
  $$J = \int r^2\,dm$$
- 单位：$\text{kg}\cdot\text{m}^2$

**常见刚体转动惯量**
| 刚体形状 | 转轴位置 | 转动惯量 $J$ |
|:---|:---|:---|
| 细圆环/圆环壳 | 垂直于环面过中心 | $mR^2$ |
| 圆盘/实心圆柱 | 垂直于盘面过中心 | $\frac{1}{2}mR^2$ |
| 细长直杆 | 垂直于杆过中心 | $\frac{1}{12}mL^2$ |
| 细长直杆 | 垂直于杆过一端 | $\frac{1}{3}mL^2$ |
| 实心球 | 过球心 | $\frac{2}{5}mR^2$ |
| 薄球壳 | 过球心 | $\frac{2}{3}mR^2$ |

**性质**
- **可加性**：对同一转轴，各部分转动惯量之和等于整个刚体的转动惯量。

---

### 四、平行轴定理

**核心概念/定义**
- 用于计算刚体对任意平行轴的转动惯量。

**定理/定律/公式**
- 设刚体对通过质心转轴的转动惯量为 $J_C$，对另一平行轴的转动惯量为 $J$，两轴距离为 $d$，刚体质量为 $m$：
  $$J = J_C + md^2$$

## 4-3 角动量 角动量守恒定律

### 一、质点的角动量定理和角动量守恒定律

**核心概念/定义**
- **质点角动量 $\boldsymbol{L}$**：位矢 $\boldsymbol{r}$ 与动量 $\boldsymbol{p}$ 的矢积。
  $$\boldsymbol{L} = \boldsymbol{r} \times \boldsymbol{p} = \boldsymbol{r} \times m\boldsymbol{v}$$
- 大小：$L = mvr\sin\theta = mvr_\perp$（$r_\perp$ 为位矢到动量方向的垂直距离）。

**定理/定律/公式**
- **角动量定理**（微分形式）：
  $$\boldsymbol{M} = \frac{d\boldsymbol{L}}{dt}$$
  （合外力矩等于角动量对时间的变化率）
- **角动量守恒定律**：
  $$\text{若 } \boldsymbol{M} = 0 \Rightarrow \boldsymbol{L} = \text{恒矢量}$$

---

### 二、刚体定轴转动的角动量定理和角动量守恒定律

**核心概念/定义**
- **刚体定轴角动量**：
  $$L = J\omega$$
- **冲量矩**：力矩在时间上的累积 $\int_{t_1}^{t_2} M\,dt$，单位 $\text{N}\cdot\text{m}\cdot\text{s}$。

**定理/定律/公式**
- **角动量定理**（积分形式）：
  $$\int_{t_1}^{t_2} M\,dt = L_2 - L_1 = J\omega_2 - J\omega_1$$
- **角动量守恒定律**：
  $$\text{若 } M = 0 \Rightarrow L = J\omega = \text{常量}$$

**适用条件与物理意义**
1. $J$ 不变时 → $\omega$ 保持不变（匀速转动）。
2. $J$ 可变时（如花样滑冰收臂、跳水运动员蜷缩）→ $\omega$ 随 $J$ 变化，但 $J\omega$ 乘积恒定。
3. **多刚体系统**：若系统合外力矩为零，系统总角动量守恒。碰撞/打击瞬间常近似满足此条件。

**典型解题套路（角动量守恒类）**
- **Step 1**：定系统——将相互作用物体视为一个系统。
- **Step 2**：判守恒——分析外力矩：重力过转轴力矩为零，轴支持力力矩为零 → 合外力矩 $M_{\text{外}} \approx 0$。
- **Step 3**：列初末态角动量——质点角动量 $L = mvr_\perp$，刚体角动量 $L = J\omega$。
- **Step 4**：列守恒式 $L_{\text{初}} = L_{\text{末}}$，结合 $v = r\omega$ 求解。
- **⚠️ 注意**：此类问题通常**动量不守恒**（轴处有冲力），**机械能不守恒**（碰撞有内能损耗），**仅角动量守恒**。

## 4-4 力矩做功 刚体绕定轴转动的动能定理

### 一、力矩做功

**核心概念/定义**
- 力矩在空间角位移上的累积效应。法向分力不做功，仅切向分力做功。

**定理/定律/公式**
- 元功：
  $$dW = F_\tau\,ds = F_\tau r\,d\theta = M\,d\theta$$
- 总功（角位置由 $\theta_1$ 变至 $\theta_2$）：
  $$W = \int_{\theta_1}^{\theta_2} M\,d\theta$$

### 二、力矩的功率
  $$P = \frac{dW}{dt} = M\omega$$

### 三、转动动能

**核心概念/定义**
- 刚体因定轴转动而具有的动能，等于所有质元动能之和。

**定理/定律/公式**
  $$E_k = \sum \frac{1}{2}\Delta m_i v_i^2 = \frac{1}{2}\left(\sum \Delta m_i r_i^2\right)\omega^2 = \frac{1}{2}J\omega^2$$

### 四、刚体绕定轴转动的动能定理

**核心概念/定义**
- 外力矩对刚体所做的功等于刚体转动动能的增量。

**定理/定律/公式**
  $$W = \int_{\theta_1}^{\theta_2} M\,d\theta = \frac{1}{2}J\omega_2^2 - \frac{1}{2}J\omega_1^2$$

**适用条件/物理模型**
- 适用于刚体定轴转动过程。
- 若系统包含平动物体与转动刚体，常结合**机械能守恒定律**联立求解（如滑轮-重物系统）。

---

### 🔹 典型解题套路汇总

#### 套路 1：转动定律综合题（滑轮-重物系统）
- **Step 1**：隔离研究对象（物体 A、物体 B、滑轮）。
- **Step 2**：受力分析。物体列牛顿第二定律 $mg - T = ma$；滑轮列转动定律 $(T_2 - T_1)r = J\beta$。
- **Step 3**：建立约束关系——线角关系 $a = r\beta$。
- **Step 4**：联立方程组求解 $a, \beta, T$。

#### 套路 2：机械能守恒/动能定理（含转动）
- **Step 1**：选系统——将平动物体、转动刚体及地球视为系统。
- **Step 2**：判守恒——若只有重力做功（轴处光滑、绳轻且无滑动），机械能守恒。
- **Step 3**：列方程：
  $$mgh = \frac{1}{2}mv^2 + \frac{1}{2}J\omega^2$$
- **Step 4**：代入 $v = R\omega$ 及对应 $J$，求解末速度或角速度。
