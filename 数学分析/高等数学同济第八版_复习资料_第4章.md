# 第4章 不定积分

> 期末命题权重：核心计算章，直接考题占比约 20%~25%，是定积分、微分方程计算的前置基础。**积分算不对，后续全白费**。

---

## 4-1 不定积分的概念与性质

### 核心概念/定理

#### 1. 原函数
**前提条件**：$f(x)$ 在区间 $I$ 上连续（初等函数在定义区间上必连续）。
若存在 $F(x)$ 使得 $F'(x) = f(x)$（$\forall x \in I$），则称 $F(x)$ 是 $f(x)$ 在 $I$ 上的一个原函数。

**原函数存在定理**：若 $f(x) \in C(I) \Rightarrow f(x)$ 在 $I$ 上一定存在原函数。
初等函数在定义区间上有原函数。

**原函数性质**：若 $f(x)$ 存在原函数，则原函数有无穷多个，且任意两个原函数之间相差一个常数。
即：若 $F'(x) = f(x)$，$G'(x) = f(x)$，则 $G(x) = F(x) + C$（$C$ 为任意常数）。

#### 2. 不定积分
$f(x)$ 在区间 $I$ 内的原函数全体称为 $f(x)$ 的不定积分，记作：
$$\int f(x)dx = F(x) + C \quad (C \text{ 为任意常数})$$
其中 $\int$ 为积分号，$f(x)$ 为被积函数，$f(x)dx$ 为被积表达式，$x$ 为积分变量，$C$ 为积分常数。

#### 3. 不定积分的几何意义
$f(x)$ 的原函数的图形称为 $f(x)$ 的积分曲线；$\int f(x)dx$ 的图形是 $f(x)$ 的所有积分曲线组成的平行曲线族。

**初值问题**：带有初始条件 $y|_{x=x_0}=y_0$ 的求原函数问题，即
$$\left\{\begin{array}{l} y^{\prime}(x)=f(x)\\ y|_{x=x_0}=y_0\end{array}\right.$$
将 $(x_0, y_0)$ 代入 $y = F(x) + C$ 解得 $C=y_0-F(x_0)$，得到所求积分曲线 $y = F(x) + C_0$。

### 核心公式

**不定积分与微分的互逆关系**：
$$\frac{d}{d x}\left[\int f(x) d x\right]=f(x), \quad d\left[\int f(x) d x\right]=f(x) d x$$

### 核心积分性质
**前提条件**：$f(x), g(x)$ 在区间 $I$ 内存在原函数。
1. $\int[f(x)\pm g(x)] d x=\int f(x) d x\pm\int g(x) d x$
2. $\int k f(x) d x=k\int f(x) d x$（$k$ 是常数，$k\neq 0$）
推广：若 $f(x) = \sum_{i=1}^{n} k_i f_i(x)$，则 $\int f(x) d x=\sum_{i=1}^n k_i\int f_i(x) d x$

### ⚠️ 易错点与防坑指南
- **不定积分结果必须加任意常数 $C$**：这是不定积分和求导最本质的区别，漏写 $C$ 直接扣一半分。
- **原函数的可导性**：$F(x)$ 是 $f(x)$ 的原函数 $\Rightarrow$ $F(x)$ 可导，但 $f(x)$ 不一定可导（仅连续）。
- **互逆运算的验证**：求导结果再积分要加 $C$，积分结果再求导等于原被积函数，即 $\int F'(x)dx = F(x) + C$，$\frac{d}{dx}\int f(x)dx = f(x)$。

### 🔑 典型解题套路（SOP）

**求过定点的积分曲线**：
- Step 1：求不定积分 $\int f(x)dx = F(x) + C$，得到积分曲线族；
- Step 2：代入初始条件 $y(x_0) = y_0$，解出 $C = y_0 - F(x_0)$；
- Step 3：写出所求积分曲线 $y = F(x) + C_0$。

## 4-2 基本积分公式表

### 核心公式（必背，期末直接调用）

| 序号 | 公式 | 备注 |
|:-----|:-----|:-----|
| (1) | $\int 0 dx = C$ | 常数的原函数 |
| (2) | $\int 1 dx = x + C$ | 幂函数特例 |
| (3) | $\int x^{\mu} dx=\frac{x^{\mu+1}}{\mu+1}+C$ | $\mu\neq-1$ |
| (4) | $\int\frac{dx}{x}=\ln|x|+C$ | 务必加绝对值 |
| (5) | $\int a^x dx=\frac{a^x}{\ln a}+C$ | $a>0,a\neq1$ |
| (6) | $\int e^x dx=e^x+C$ | 指数函数特例 |
| (7) | $\int \cos xdx = \sin x + C$ | 三角公式 |
| (8) | $\int \sin xdx = -\cos x + C$ | 三角公式 |
| (9) | $\int \sec^2 x dx = \tan x + C$ | 即 $\int \frac{dx}{\cos^2 x}$ |
| (10) | $\int \csc^2 x dx = -\cot x + C$ | 即 $\int \frac{dx}{\sin^2 x}$ |
| (11) | $\int \sec x \tan xdx = \sec x + C$ | 三角公式 |
| (12) | $\int \csc x \cot x dx = -\csc x + C$ | 三角公式 |
| (13) | $\int\frac{1}{\sqrt{1-x^2}} dx=\arcsin x+C$ | 或 $-\arccos x+C$ |
| (14) | $\int\frac{1}{1+x^2} dx=\arctan x+C$ | 或 $-\operatorname{arccot}x+C$ |
| (15) | $\int \tan x dx=-\ln |\cos x|+C$ | 凑微分推导 |
| (16) | $\int \cot x dx=\ln \left|\sin x\right|+C$ | 凑微分推导 |
| (17) | $\int \sec x dx=\ln |\sec x+\tan x|+C$ | 凑微分推导 |
| (18) | $\int \csc x dx=\ln \left|\csc x-\cot x\right|+C$ | 凑微分推导 |
| (19) | $\int \frac{1}{a^2+x^2} dx=\frac{1}{a} \arctan \frac{x}{a}+C$ | $a>0$ |
| (20) | $\int \frac{1}{x^2-a^2} dx=\frac{1}{2 a} \ln \left|\frac{x-a}{x+a}\right|+C$ | $a>0$ |
| (21) | $\int \frac{1}{a^2-x^2} dx=\frac{1}{2 a} \ln \left|\frac{a+x}{a-x}\right|+C$ | $a>0$ |
| (22) | $\int \frac{1}{\sqrt{a^2-x^2}} dx=\arcsin \frac{x}{a}+C$ | $a>0$ |
| (23) | $\int \frac{1}{\sqrt{x^2 \pm a^2}} dx=\ln \left|x+\sqrt{x^2 \pm a^2}\right|+C$ | $a>0$ |

### ⚠️ 易错点与防坑指南
- **$\int \frac{1}{x}dx = \ln|x| + C$ 必须加绝对值**：若漏掉绝对值，在 $x<0$ 时会出错。
- **$\int \frac{1}{1+x^2}dx$ 结果是 $\arctan x + C$，不是 $\arcsin x + C$**：反三角公式极易混淆，需牢记导数对应关系。
- **$\int a^x dx = \frac{a^x}{\ln a} + C$ 分母是 $\ln a$，不是 $\ln x$**：与 $\int e^x dx = e^x + C$ 区分开。

### 🔑 典型解题套路（SOP）

**直接积分法（恒等变形后直接用基本公式）**：
- Step 1：对被积函数进行恒等变形（分项、通分、利用三角公式、代数公式化简）；
- Step 2：利用不定积分的线性性质拆分积分；
- Step 3：逐项匹配基本积分公式，计算后加 $C$。

**例**：$\int \left( \frac{3}{1+x^2} - \frac{2}{\sqrt{1-x^2}} \right) dx = 3\arctan x - 2\arcsin x + C$

## 4-3 换元积分法

### 4-3-1 第一类换元法（凑微分法）

#### 核心概念/定理
**前提条件**：$\int f(u)du = F(u) + C$，且 $u = \varphi(x)$ 可微。
$$\int f[\varphi(x)]\varphi^{\prime}(x) d x=F[\varphi(x)]+C$$
可形象地表述为：
$$\int f[\varphi(x)]\varphi^{\prime}(x) d x=\int f[\varphi(x)] d\varphi(x)=\int f(u) d u=F(u)+C=F[\varphi(x)]+C$$

#### 核心公式（常用凑微分形式）
1. $\int f(ax + b) d x=\frac{1}{a}\int f(ax + b) d(ax + b)$
2. $\int f(x^n) x^{n-1}dx = \frac{1}{n}\int f(x^n) dx^n$
3. $\int f(\sin x)\cos x dx = \int f(\sin x) d\sin x$
4. $\int f(\cos x)\sin x dx = -\int f(\cos x) d\cos x$
5. $\int f(\tan x) \sec^2 x dx = \int f(\tan x) d\tan x$
6. $\int f(e^x)e^x dx = \int f(e^x) de^x$
7. $\int f(\ln x) \frac{1}{x}dx = \int f(\ln x) d\ln x$
8. $\int f(\arcsin x) \frac{1}{\sqrt{1-x^2}} dx = \int f(\arcsin x) d(\arcsin x)$
9. $\int f(\arctan x) \frac{1}{1+x^2} dx = \int f(\arctan x) d(\arctan x)$

#### ⚠️ 易错点与防坑指南
- **凑微分的核心是找到 $\varphi'(x)$ 因子**：若被积表达式中缺少 $\varphi'(x)$，不能随意添加系数，需调整常数（如 $\int \frac{1}{3+2x}dx = \frac{1}{2}\int \frac{1}{3+2x}d(3+2x)$）。
- **换元后必须还原为原积分变量**：最终结果中不能保留中间变量 $u$，需回代 $u = \varphi(x)$。
- **同一积分可凑不同微分，结果形式不同但仅相差常数**：如 $\int \sin2xdx = -\frac{1}{2}\cos2x + C = \sin^2x + C = -\cos^2x + C$，验证时求导即可。

#### 🔑 典型解题套路（SOP）

**凑微分法标准流程**：
- Step 1：观察被积函数，识别复合函数结构 $f[\varphi(x)]$ 和微分因子 $\varphi'(x)$；
- Step 2：凑出微分形式 $\int f[\varphi(x)] d\varphi(x)$，令 $u = \varphi(x)$；
- Step 3：计算 $\int f(u)du = F(u) + C$；
- Step 4：回代 $u = \varphi(x)$，得到最终结果加 $C$。

### 4-3-2 第二类换元法

#### 核心概念/定理
**前提条件**：$x = \varphi(t)$ 是单调、可导函数，且 $\varphi'(t) \neq 0$；又设 $f[\varphi(t)]\varphi'(t)$ 具有原函数 $F(t)$，则：
$$\int f(x) d x=F\left[\varphi^{-1}(x)\right]+C$$
其中 $t = \varphi^{-1}(x)$ 是 $x = \varphi(t)$ 的反函数。

#### 适用场景与常用代换
| 代换类型 | 适用场景 | 代换公式 | 反函数还原 |
|:-----|:-----|:-----|:-----|
| **三角代换** | 被积函数含 $\sqrt{a^2-x^2}$ | $x = a\sin t,\ t\in(-\frac{\pi}{2},\frac{\pi}{2})$ | $\sin t = \frac{x}{a},\ \cos t = \frac{\sqrt{a^2-x^2}}{a}$ |
| | 被积函数含 $\sqrt{a^2+x^2}$ | $x = a\tan t,\ t\in(-\frac{\pi}{2},\frac{\pi}{2})$ | $\tan t = \frac{x}{a},\ \sec t = \frac{\sqrt{a^2+x^2}}{a}$ |
| | 被积函数含 $\sqrt{x^2-a^2}$ | $x = a\sec t,\ t\in(0,\frac{\pi}{2})$ | $\sec t = \frac{x}{a},\ \tan t = \frac{\sqrt{x^2-a^2}}{a}$ |
| **倒代换** | 分母阶数较高（如含 $x^n$ 在分母，$n\geq7$） | $x = \frac{1}{t},\ t\neq0$ | $t = \frac{1}{x}$ |
| **根式代换** | 被积函数含 $\sqrt[n]{ax+b}$ 或多种根式 | $t = \sqrt[n]{ax+b}$ 或 $x = t^N$（$N$ 为根指数最小公倍数） | $x = t^N$ 回代 |

#### 典型例题对应代换
1. $\int \frac{1}{\sqrt{x^2 + a^2}} dx$：令 $x = a\tan t$，结果 $\ln\left(x+\sqrt{x^2+a^2}\right)+C$
2. $\int x^3 \sqrt{4 - x^2} dx$：令 $x = 2\sin t$，结果 $-\frac{4}{3}\left(\sqrt{4-x^2}\right)^3+\frac{1}{5}\left(\sqrt{4-x^2}\right)^5+C$
3. $\int \frac{1}{x(x^7 + 2)} dx$：令 $x = \frac{1}{t}$，结果 $-\frac{1}{14} \ln \left|2+x^7\right|+\frac{1}{2} \ln \left|x\right|+C$
4. $\int \frac{x^5}{\sqrt{1+x^2}} dx$：令 $t = \sqrt{1+x^2}$，结果 $\frac{1}{15}\left(8-4 x^2+3 x^4\right)\sqrt{1+x^2}+C$

#### ⚠️ 易错点与防坑指南
- **第二类换元必须保证代换单调可导**：三角代换的区间选择要保证反函数存在，如 $x = a\sin t$ 选 $t\in(-\frac{\pi}{2},\frac{\pi}{2})$ 保证 $\cos t>0$，开方直接去根号。
- **换元必须一起换**：$x = \varphi(t)$ 时，$dx = \varphi'(t)dt$，两者必须同时替换，不能只换 $x$ 不换 $dx$。
- **不是所有根式都必须用三角代换**：如 $\int \frac{x^5}{\sqrt{1+x^2}}dx$ 用根式代换 $t=\sqrt{1+x^2}$ 比三角代换更简便，需根据被积函数灵活选择。

#### 🔑 典型解题套路（SOP）

**三角代换标准流程**：
- Step 1：根据根式类型选择对应三角代换，写出 $x = \varphi(t)$ 和 $dx = \varphi'(t)dt$；
- Step 2：代入被积表达式，利用三角恒等式化简（如 $1-\sin^2t=\cos^2t$）；
- Step 3：计算关于 $t$ 的积分，得到 $F(t) + C$；
- Step 4：根据直角三角形或反三角函数关系，将 $t$ 回代为 $x$ 的表达式，得到最终结果加 $C$。
> **💡 辅助三角形画法**：以 $x=a\sin t$ 为例，画一个直角三角形，设对边为 $x$，斜边为 $a$，则邻边为 $\sqrt{a^2-x^2}$，从而 $\cos t = \frac{\sqrt{a^2-x^2}}{a}$，$\tan t = \frac{x}{\sqrt{a^2-x^2}}$。其他代换同理，画图回代绝不迷路。

## 4-4 分部积分法

### 核心概念/定理
**前提条件**：$u = u(x)$ 和 $v = v(x)$ 具有连续导数。
由 $(uv)' = u'v + uv'$ 得分部积分公式：
$$\int u d v=u v-\int v d u$$
或等价形式：
$$\int u v^{\prime} d x=u v-\int u^{\prime} v d x$$

### 核心选 $u$ 原则：反对幂指三（LIATE）

| 优先级 | 函数类型 | 选 $u$ 场景 | 示例 |
|:-----|:-----|:-----|:-----|
| 1 | 反三角函数（L） | 反三角函数 × 幂函数/指数/三角 | $\int x\arctan x dx$ 选 $u=\arctan x$ |
| 2 | 对数函数（I） | 对数函数 × 幂函数/指数/三角 | $\int x^3\ln x dx$ 选 $u=\ln x$ |
| 3 | 幂函数（A） | 幂函数 × 指数/三角 | $\int x e^x dx$ 选 $u=x$ |
| 4 | 指数函数（T） | 指数 × 三角（两者优先级相当，选谁都可） | $\int e^x\sin x dx$ 选 $u=\sin x$ 或 $u=e^x$ |
| 5 | 三角函数（E） | 三角 × 其他更低优先级 | — |

### 典型题型总结
1. **幂函数 × 指数/三角**：选幂函数为 $u$，降幂一次（如 $\int x^2 e^x dx$ 需两次分部积分）
2. **幂函数 × 反三角/对数**：选反三角/对数为 $u$（如 $\int x\arctan x dx$）
3. **指数 × 三角**：循环形式，移项解出积分（如 $\int e^x\sin x dx = \frac{e^x}{2}(\sin x-\cos x)+C$）
4. **含变上限积分/导数已知**：结合微分和分部积分（如已知 $f(x)$ 的原函数是 $e^{-x^2}$，求 $\int x f'(x)dx$）

### ⚠️ 易错点与防坑指南
- **$u$ 和 $dv$ 选择错误会导致积分越来越复杂**：如 $\int x\cos xdx$ 若选 $u=\cos x$，$dv=xdx$，则积分变为 $\frac{x^2}{2}\cos x + \int \frac{x^2}{2}\sin xdx$，更复杂。
- **循环积分不要无限循环**：出现 $\int e^x\sin x dx$ 类型时，两次分部积分后会出现原积分，移项合并即可，不要继续积分。
- **⚠️ 致命警告**：在计算 $\int e^x \sin x dx$ 时，两次分部积分必须保持 $u$ 和 $dv$ 的选择一致性（即第一次选 $u=\sin x$，第二次也必须选三角/指数部分作为 $u$，不能中途交换），否则会导致恒等式 $0=0$ 的灾难！
- **分部积分后必须加 $C$**：即使经过移项，最终结果仍需加任意常数 $C$。

### 🔑 典型解题套路（SOP）

**分部积分标准流程**：
- Step 1：根据"反对幂指三"原则选择 $u$ 和 $dv$（$dv$ 要容易积分得到 $v$）；
- Step 2：计算 $du = u'dx$，$v = \int dv$；
- Step 3：代入公式 $\int u dv = uv - \int v du$，计算右侧积分；
- Step 4：若出现循环，移项解出原积分；若需多次分部，重复 Step 1-3；
- Step 5：加任意常数 $C$。

## 4-5 有理函数的积分

### 核心概念/定理
**有理函数定义**：两个多项式的商表示的函数，即
$$R(x) = \frac{P(x)}{Q(x)} = \frac{a_0x^n + a_1x^{n-1} + \cdots + a_n}{b_0x^m + b_1x^{m-1} + \cdots + b_m}$$
其中 $m,n$ 为非负整数，$a_0\neq0, b_0\neq0$。
- 若 $n < m$：真分式；若 $n \geq m$：假分式，可化为多项式 + 真分式之和（多项式除法）。

### 部分分式分解规律
| 分母因式类型 | 分解形式 |
|:-----|:-----|
| 单因式 $(x-a)^k$ | $\frac{A_1}{x-a} + \frac{A_2}{(x-a)^2} + \cdots + \frac{A_k}{(x-a)^k}$ |
| 二次不可约因式 $(x^2+px+q)^k$（$p^2-4q<0$） | $\frac{M_1x+N_1}{x^2+px+q} + \frac{M_2x+N_2}{(x^2+px+q)^2} + \cdots + \frac{M_kx+N_k}{(x^2+px+q)^k}$ |

### 三类可积情况
1. **多项式**：直接积分；
2. **$\int \frac{A}{(x-a)^n}dx$**：
   - $n=1$：$\int \frac{A}{x-a}dx = A\ln|x-a| + C$
   - $n>1$：$\int \frac{A}{(x-a)^n}dx = \frac{A}{-n+1}(x-a)^{-n+1} + C$
3. **$\int \frac{Mx+N}{(x^2+px+q)^n}dx$**：
   - 配方 $x^2+px+q = (x+\frac{p}{2})^2 + \frac{4q-p^2}{4} = t^2 + a^2$，令 $t = x+\frac{p}{2}$；
   - 拆为 $\int \frac{Mt}{t^2+a^2}dt + \int \frac{b}{t^2+a^2}dt$（$b = N - \frac{Mp}{2}$），分别积分得对数项和反正切项。

### ⚠️ 易错点与防坑指南
- **假分式必须先做多项式除法**：不能直接分解部分分式，如 $\frac{x^4}{1+x^2} = x^2 -1 + \frac{1}{1+x^2}$，再分项积分。
- **部分分式分解的待定系数要算准**：可通过赋值法（令 $x$ 取特殊值）或比较系数法求解 $A_i, M_i, N_i$，避免计算错误。
- **有理函数积分尽量用凑微分简化**：如 $\int \frac{1+2x^2}{x^2(1+x^2)}dx = \int \frac{1}{x^2}dx + \int \frac{1}{1+x^2}dx = -\frac{1}{x} + \arctan x + C$，无需机械分解部分分式。

### 🔑 典型解题套路（SOP）

**有理函数积分标准流程**：
- Step 1：若为假分式，先做多项式除法化为多项式 + 真分式；
- Step 2：对真分式进行部分分式分解，求出待定系数；
- Step 3：分项积分，利用基本积分公式和凑微分法计算每一项；
- Step 4：合并结果加 $C$。

## 4-6 积分表的使用

### 核心说明
教材附录Ⅳ给出了常用积分公式表，适用于复杂积分的直接查用，使用注意：
1. 先对被积函数做简单变形，匹配积分表中的公式形式；
2. 注意公式中参数的取值范围（如 $a>0$、$|x|<a$ 等）；
3. 查表结果仍需加任意常数 $C$，且需回代为原变量。

### 常用查表积分类型
- 含 $\sqrt{a^2 \pm x^2}$、$\sqrt{x^2 \pm a^2}$ 的积分；
- 含 $\int \frac{dx}{(x^2+a^2)^n}$ 的递推公式；
- 含三角函数的幂次积分；
- 含指数函数、对数函数的组合积分。

## 📋 第四章速查：积分方法选择优先级

$$\boxed{\text{直接积分法(恒等变形)} \ \to\ \text{凑微分法} \ \to\ \text{第二类换元法(三角/倒/根式代换)} \ \to\ \text{分部积分法}}$$

| 被积函数特征 | 首选方法 |
|:-----|:-----|
| 可直接匹配基本积分公式 | 直接积分法 |
| 含复合函数 $f[\varphi(x)]$ 且有 $\varphi'(x)$ 因子 | 凑微分法 |
| 含 $\sqrt{a^2-x^2}/\sqrt{a^2+x^2}/\sqrt{x^2-a^2}$ | 三角代换 |
| 分母阶数≥7 或含 $x^n$ 在分母 | 倒代换 $x=1/t$ |
| 含 $\sqrt[n]{ax+b}$ 或多种根式 | 根式代换 |
| 幂函数×反三角/对数 | 分部积分，选反三角/对数为 $u$ |
| 幂函数×指数/三角 | 分部积分，选幂函数为 $u$ |
| 指数×三角 | 分部积分，循环移项 |
| 多项式/假分式 | 多项式除法 + 部分分式分解 |
