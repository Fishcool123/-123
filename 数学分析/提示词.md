## 二、文档格式规范

每个章文件必须严格遵循以下结构（参考已有12章文件）：

```markdown
<!-- METADATA -->

| 属性 | 内容 |
|:-----|:-----|
| **书名** | 《高等数学》第八版 上/下册 |
| **主编** | 同济大学数学科学学院 |
| **版本** | 第八版 |
| **适用对象** | 高等院校工科类专业本科生、考研（数学一/二）备考者 |
| **文档用途** | 期末复习·命题人视角核心考点精析 |
| **内容来源** | 共享知识库 + 讲义 + 板书 |

---

<!-- CHAPTER: N -->

# 第N章 章节名称

> 期末命题权重：...%，核心是...

---

## N-1 节名

### 核心概念/定理
（概念解释 + 定理陈述，用表格或列表）

### 核心公式
（公式用 LaTeX，`$$` 块级或 `$` 行内）

### ⚠️ 易错点与防坑指南
（每个易错点用 `- **标题**：说明` 格式）

### 🔑 典型解题套路（SOP）
（Step 1 → Step 2 → Step 3 分步拆解）

---

## N-2 节名
（重复上述结构）
```

### 格式要求细节

1. **公式**：全部用 LaTeX 语法（`$...$` 行内，`$$...$$` 块级），与物理 Formula_Cheatsheet.md 风格一致
2. **表格**：用 Markdown 原生表格，对齐符号 `|:---|:---|`
3. **警告标识**：⚠️ 用于易错点，💡 用于技巧提示，🔑 用于解题套路
4. **关键公式**：用 `\boxed{}` 包裹
5. **标题层级**：`#` 章 → `##` 节 → `###` 子主题
6. **语言**：中文为主体，技术术语保留原词（如 $\varepsilon$-$N$、SOP）

## 四、速查表生成通用提示词模板

如果想对某个章节单独生成公式速查表，用这个模板：

```
请根据【章节名称】的内容，生成一份 A4 打印版公式速查表。

要求：
1. 只保留考试必考的核心公式，不写推导过程
2. 用表格并列呈现，节省空间
3. 每个公式后面标注 ⚠️ 易错点（如常见遗漏项、符号错误）
4. 添加 puppeteer YAML frontmatter（A4、scale:0.9、页眉页脚），与物理 Formula_Cheatsheet.md 风格统一
5. 最后加一句「考场上最容易忘的3个东西」
```

## 五、使用方式

### 在新会话中继续工作

1. 把本 `提示词.md` 的内容粘贴给 AI
2. 把对应任务涉及的 PDF/docx/照片文件一并上传
3. 指定任务编号（A/B/C/D/E）或直接给新任务
4. 要求 AI 输出 Markdown 文件，放到 `数学分析/` 目录下

### 质量检查清单

生成后检查：
- [ ] LaTeX 公式可正常渲染（`$` 配对，无非法字符）
- [ ] 表格对齐正确
- [ ] 章-节-子主题层级正确
- [ ] 易错点确实是常见错误（不写废话型提醒）
- [ ] 解题套路 Step 完整、可操作
- [ ] 无虚构内容、TODO 占位或省略号
