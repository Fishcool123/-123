# 第7章 微分方程

> 期末命题权重：压轴章，直接考题占比约 20%~25%。核心是**方程类型识别 + 标准解法套用**，特解设法是拉开分差的关键战场。

---

## 7-1 微分方程的基本概念

### 核心概念/定理

| 概念 | 定义 | 示例 |
|:-----|:-----|:-----|
| **微分方程** | 含自变量、未知函数及其导数的方程 | $y' + y = e^x$ |
| **阶数** | 方程中出现的最高阶导数的阶数 | $y'' + y = 0$（二阶） |
| **通解** | 含有与阶数相同个数的独立任意常数的解 | $y = Ce^{-x} + \frac{1}{2}e^x$ |
| **特解** | 不包含任意常数的解（由初始条件确定常数） | 给 $y(0)=1$ 后定出 $C=\frac{1}{2}$ |
| **初始条件** | $y(x_0)=y_0,\ y'(x_0)=y_0',\ \ldots$ | $y(0)=0,\ y'(0)=1$ |
| **初值问题** | 微分方程 + 初始条件 | $\begin{cases} y''+y=0 \\ y(0)=0,\ y'(0)=1 \end{cases}$ |

### ⚠️ 易错点与防坑指南

- **通解中独立任意常数的个数 = 方程的阶数**：一阶一个 $C$，二阶两个 $C_1, C_2$。
- **通解 ≠ 全体解**：有些方程还有不能通过通解取特定常数得到的奇解。
- **初始条件可以确定全部待定常数**：二阶方程需要两个初始条件（$y_0$ 和 $y_0'$）。

## 7-2 可分离变量的微分方程

### 核心概念/定理

**标准形式**：
$$\boxed{\frac{dy}{dx} = f(x) \cdot g(y)}$$

**前提条件**：$g(y) \neq 0$。

### 核心公式

**解法（分离变量 → 积分）**：
$$\frac{dy}{g(y)} = f(x)dx \ \Longrightarrow\ \int \frac{dy}{g(y)} = \int f(x)dx + C$$

**可化为可分离变量的方程**：$y' = f(ax+by+c)$

令 $u = ax+by+c$，则 $\frac{du}{dx} = a + b\frac{dy}{dx}$，代入得 $\frac{du}{dx} = a + b f(u)$，即可分离变量。

### ⚠️ 易错点与防坑指南

- **分离变量时 $g(y) = 0$ 的解可能是奇解**：将 $g(y) = 0$ 的根 $y = y_0$ 代入原方程验证，若成立则可能是通解之外的特解。
- **积分常数 $C$ 不能遗漏**：两侧积分各有一个常数，但合并为一个 $C$ 即可。

### 🔑 典型解题套路（SOP）

**可分离变量方程标准流程**：
- Step 1：识别方程是否形如 $\frac{dy}{dx} = f(x)g(y)$；
- Step 2：分离变量：$\frac{dy}{g(y)} = f(x)dx$；
- Step 3：两边积分，加常数 $C$；
- Step 4：若可能，解出显式通解 $y = y(x, C)$。

## 7-3 齐次方程

### 核心概念/定理

**标准形式**：
$$\boxed{\frac{dy}{dx} = f\!\left(\frac{y}{x}\right)}$$

**识别特征**：用 $tx$ 替换 $x$、$ty$ 替换 $y$ 后，方程形式不变。

### 核心公式

**解法（换元 $u = \frac{y}{x}$）**：

令 $y = xu$，则 $\frac{dy}{dx} = u + x\frac{du}{dx}$，代入原方程得：
$$u + x\frac{du}{dx} = f(u) \ \Longrightarrow\ x\frac{du}{dx} = f(u) - u$$

化为可分离变量方程：
$$\frac{du}{f(u)-u} = \frac{dx}{x}$$

**可化为齐次方程的方程**：$y' = \frac{a_1 x + b_1 y + c_1}{a_2 x + b_2 y + c_2}$

若 $\frac{a_1}{a_2} \neq \frac{b_1}{b_2}$，通过平移变换 $X = x - \alpha,\ Y = y - \beta$（其中 $(\alpha, \beta)$ 为两直线交点）化为 $\frac{dY}{dX} = \frac{a_1 X + b_1 Y}{a_2 X + b_2 Y}$，即为齐次方程。

### ⚠️ 易错点与防坑指南

- **齐次方程最终的 $u$ 必须回代为 $\frac{y}{x}$**。
- **平移变换求出 $(\alpha, \beta)$ 必须解联立方程组**：$\begin{cases} a_1 \alpha + b_1 \beta + c_1 = 0 \\ a_2 \alpha + b_2 \beta + c_2 = 0 \end{cases}$。

## 7-4 一阶线性微分方程

### 核心概念/定理

**标准形式**：
$$\boxed{\frac{dy}{dx} + P(x)y = Q(x)}$$

- **齐次（$Q(x) \equiv 0$）**：$\frac{dy}{dx} + P(x)y = 0$ — 可分离变量
- **非齐次（$Q(x) \not\equiv 0$）**：需要积分因子法

### 核心公式

**冲核心公式（通解公式 —— 直接背诵，考场秒杀）**：

$$\boxed{y = e^{-\int P(x)dx}\left[\int Q(x) e^{\int P(x)dx} dx + C\right]}$$

**分步理解**：
1. 积分因子 $\mu(x) = e^{\int P(x)dx}$
2. 方程两边乘 $\mu(x)$：$\mu y' + \mu P y = \mu Q \ \Longrightarrow\ (\mu y)' = \mu Q$
3. 积分：$\mu y = \int \mu Q dx + C$
4. 解出 $y = \frac{1}{\mu}\left[\int \mu Q dx + C\right]$

### ⚠️ 易错点与防坑指南

- **必须先把方程写成标准形式**：$\frac{dy}{dx} + P(x)y = Q(x)$，系数配平后再套公式。
- **积分因子公式中的 $P(x)$ 前面没有负号**：$\mu = e^{\int P(x)dx}$，不要写成 $e^{-\int P(x)dx}$。
- **伯努利方程**：$y' + P(x)y = Q(x)y^n\ (n\neq0,1)$，令 $z = y^{1-n}$ 化为一阶线性方程求解。（**实操提示**：方程两边同除以 $y^n$，再同乘 $(1-n)$，即可化为关于 $z$ 的标准一阶线性方程 $\frac{dz}{dx} + (1-n)P(x)z = (1-n)Q(x)$。）

## 7-5 可降阶的高阶微分方程

### 核心概念/定理

**三种可降阶类型**：

| 类型 | 特征 | 降阶方法 |
|:-----|:-----|:---------|
| $y^{(n)} = f(x)$ | 右端只含 $x$ | 直接逐次积分 |
| $y'' = f(x, y')$ | 不显含 $y$ | 令 $y' = p$，则 $y'' = p'$，降为一阶 |
| $y'' = f(y, y')$ | 不显含 $x$ | 令 $y' = p$，则 $y'' = p\frac{dp}{dy}$，降为 $y$ 和 $p$ 的一阶方程 |

### ⚠️ 易错点与防坑指南

- **不显含 $y$ 和不显含 $x$ 的降阶公式不同**：前者 $y'' = p'$（对 $x$ 求导），后者 $y'' = p\frac{dp}{dy}$（对 $y$ 求导）。写错直接零分。
- **逐次积分每次加一个常数**：$y'''=f(x)$ 需积分三次，产生三个常数 $C_1, C_2, C_3$。

## 7-6 高阶线性微分方程

### 核心概念/定理

**二阶线性微分方程标准形式**：
$$\boxed{y'' + p(x)y' + q(x)y = f(x)}$$

- $f(x) \equiv 0$：**齐次方程**；$f(x) \not\equiv 0$：**非齐次方程**。

**解的叠加原理**（齐次方程）：若 $y_1(x), y_2(x)$ 是齐次方程的解，则 $y = C_1 y_1 + C_2 y_2$ 也是解。

**线性无关与通解**：若 $y_1, y_2$ 线性无关，则 $y = C_1 y_1 + C_2 y_2$ 为齐次方程的通解。

**非齐次方程通解结构**：
$$\boxed{y_{\text{通}} = y_{\text{齐通}} + y_{\text{特}}}$$

即：非齐次通解 = 对应齐次方程通解 + 非齐次方程的一个特解。

### ⚠️ 易错点与防坑指南

- **解的结构定理是本章的核心骨架**：无论常系数还是变系数，通解 = 齐通 + 非齐特。
- **判断线性无关**：朗斯基行列式 $W(x) = \begin{vmatrix} y_1 & y_2 \\ y_1' & y_2' \end{vmatrix} \neq 0$ 在某点成立，则 $y_1, y_2$ 线性无关。

## 7-7 常系数齐次线性微分方程

### 核心概念/定理

**标准形式**：
$$\boxed{y'' + py' + qy = 0\quad (p, q \text{ 为常数})}$$

### 核心公式

**特征方程与通解 —— 期末必考表格**：

$$\lambda^2 + p\lambda + q = 0$$

| 判别式 $\Delta = p^2 - 4q$ | 特征根 | 齐次方程通解 |
|:--------------------------|:-------|:------------|
| $\Delta > 0$ | 两相异实根 $\lambda_1 \neq \lambda_2$ | $y = C_1 e^{\lambda_1 x} + C_2 e^{\lambda_2 x}$ |
| $\Delta = 0$ | 相等实根 $\lambda_1 = \lambda_2 = \lambda$ | $y = (C_1 + C_2 x)e^{\lambda x}$ |
| $\Delta < 0$ | 共轭复根 $\lambda = \alpha \pm i\beta$ | $y = e^{\alpha x}(C_1 \cos\beta x + C_2 \sin\beta x)$ |

### ⚠️ 易错点与防坑指南

- **重根时通解必须是 $(C_1 + C_2 x)e^{\lambda x}$**，漏掉 $x$ 因子将导致与实际特解线性相关。
- **复根时 $\alpha$ 是实部**：原方程 $y''+py'+qy=0$ 中 $\alpha = -p/2$，不是直接取 $p$。

## 7-8 常系数非齐次线性微分方程

### 核心概念/定理

**标准形式**：
$$\boxed{y'' + py' + qy = f(x)\quad (p, q \text{ 为常数})}$$

### 核心公式

> **🔴 命题人审查重点：特解 $y^*$ 的标准设法 —— 本章最高频丢分区**

**情形一：$f(x) = P_m(x)e^{\lambda x}$（$P_m(x)$ 是 $m$ 次多项式）**

| $\lambda$ 与特征根的关系 | 特解 $y^*$ 的设法 | $k$ 值 |
|:------------------------|:------------------|:------|
| $\lambda$ **不是**特征根 | $y^* = Q_m(x)e^{\lambda x}$ | $k = 0$ |
| $\lambda$ 是**单重**特征根 | $y^* = x Q_m(x)e^{\lambda x}$ | $k = 1$ |
| $\lambda$ 是**二重**特征根 | $y^* = x^2 Q_m(x)e^{\lambda x}$ | $k = 2$ |

其中 $Q_m(x)$ 是与 $P_m(x)$ 同次的**待定系数多项式**。

**情形二：$f(x) = e^{\alpha x}[P_l(x)\cos\beta x + P_n(x)\sin\beta x]$**

$$\boxed{y^* = x^k e^{\alpha x}\left[R_m(x)\cos\beta x + S_m(x)\sin\beta x\right]}$$

其中 $m = \max(l, n)$，$k$ 取决于 $\alpha \pm i\beta$ 是否为特征根：
- $\alpha \pm i\beta$ **不是**特征根 → $k = 0$
- $\alpha \pm i\beta$ **是**特征根 → $k = 1$

### ⚠️ 易错点与防坑指南

- **$k$ 值判断是整个考研高数的核心+高频+高失误考点**：$\lambda$ 是否等于特征根——必须对照特征方程 $\lambda^2 + p\lambda + q = 0$ 的根来判断，不是看 $f(x)$ 中的 $\lambda$ 和 $p,q$ 的关系。
- **$f(x)$ 为多项式**（$\lambda = 0$）：$k$ 取决于 $0$ 是否为特征根。若 $q \neq 0$（$0$ 不是根）→ $k=0$；若 $q=0, p\neq0$（$0$ 是单根）→ $k=1$；若 $p=q=0$（$0$ 是二重根）→ $k=2$。
- **待定系数法必须设全项**：$Q_m(x)$ 必须从最高次写到常数项，不能跳项。
- **特解代入原方程比较系数**：分别令等式两端 $x$ 的同次幂系数相等，解出 $Q_m(x)$ 的系数。务必代入，不要凭感觉猜。

> ⚠️ **致命陷阱（期末90%学生踩坑）**：当 $f(x) = e^{\alpha x}\cos\beta x$（或只有 $\sin\beta x$）时，特解 $y^*$ 中必须同时包含正弦和余弦两项（即 $R_m(x)\cos\beta x + S_m(x)\sin\beta x$），绝不能因为原函数只有余弦就只设余弦项！否则代入原方程后无法比较系数。

### 🔑 典型解题套路（SOP）

**常系数非齐次方程求通解标准流程**：

- Step 1：写出对应的齐次方程 $y'' + py' + qy = 0$；
- Step 2：解特征方程 $\lambda^2 + p\lambda + q = 0$，按判别式写齐次通解 $Y$；
- Step 3：分析 $f(x)$ 的类型，判断 $\lambda$（或 $\alpha \pm i\beta$）与特征根的关系，确定 $k$ 值；
- Step 4：设出特解 $y^*$ 的形式，代入原方程比较系数或求导数求解待定系数；
- Step 5：写通解 $y = Y + y^*$。

## 7-9 欧拉方程

### 核心概念/定理

**欧拉方程标准形式**：
$$\boxed{x^n y^{(n)} + p_1 x^{n-1} y^{(n-1)} + \cdots + p_{n-1} x y' + p_n y = f(x)}$$
其中 $p_i$ 为常数。

**二阶欧拉方程**（考得最多）：
$$\boxed{x^2 y'' + p x y' + q y = f(x)}$$

### 核心公式

**解法（换元 $x = e^t$ 或 $t = \ln x$）**：

令 $D = \frac{d}{dt}$，则有：
$$x y' = D y,\quad x^2 y'' = D(D-1) y$$

代入后欧拉方程化为关于 $t$ 的**常系数线性方程**，按前面方法求解即可。

**特例**：$x^2 y'' + p x y' + q y = 0$ 化为 $(D(D-1) + p D + q)y = 0$，特征方程：
$$r(r-1) + p r + q = 0$$

### ⚠️ 易错点与防坑指南

- **欧拉方程的换元方向**：$x = e^t$（$x>0$），$t = \ln x$。换元后对 $t$ 求导而非对 $x$ 求导。
- **$x < 0$ 时用 $x = -e^t$ 或 $t = \ln(-x)$**。
- **换元后的微分算子转换不能记反**：$x y' = D y,\ x^2 y'' = D(D-1)y$。
- **⚠️ 初值问题提醒**：若题目给出的是 $x=1$ 时的初始条件（如 $y(1)=1, y'(1)=2$），换元后需转换为 $t=0$ 时的初始条件。注意 $y'_x = \frac{dy}{dx} = \frac{dy/dt}{dx/dt} = e^{-t} \frac{dy}{dt}$，在 $x=1\ (t=0)$ 时，$y'_x = \frac{dy}{dt}$。

## 7-10 常系数线性微分方程组解法举例

### 核心概念/定理

**标准形式**（以二元一阶常系数线性方程组为例）：
$$\begin{cases}
x'(t) = a_{11} x + a_{12} y + f_1(t) \\
y'(t) = a_{21} x + a_{22} y + f_2(t)
\end{cases}$$

### 核心公式

**解法：消元法 — 化为一元高阶方程**：

- Step 1：从第一个方程解出 $y$（用 $x, x'$ 表示）；
- Step 2：对 $y$ 的表达式求导得 $y'$；
- Step 3：将 $y, y'$ 代入第二个方程，得到关于 $x$ 的二阶常系数线性方程；
- Step 4：解出 $x(t)$，再代入 $y$ 的表达式得 $y(t)$。

### ⚠️ 易错点与防坑指南

- **消元后阶数升高**：两个一阶方程消元后通常得到一个二阶方程，需要两个初始条件（$x(0), y(0)$）来确定常数。
- **如果解出的 $y$ 表达式含有 $x$ 的导数**：$y$ 的一阶导必须再代入方程组验证。

## 📋 第七章速查：微分方程类型识别与解法

| 方程类型 | 识别特征 | 解法 |
|:-----|:-----|:-----|
| 可分离变量 | $\frac{dy}{dx} = f(x)g(y)$ | 分离 → $\int \frac{dy}{g} = \int f dx + C$ |
| 齐次 | $y' = f(y/x)$ | 令 $u = y/x$，化可分离变量 |
| 一阶线性 | $y' + P(x)y = Q(x)$ | $y = e^{-\int P}[\int Q e^{\int P}dx + C]$ |
| $y^{(n)} = f(x)$ | 右端只含 $x$ | 逐次积分 |
| $y'' = f(x, y')$ | 不显含 $y$ | 令 $y' = p$，$y'' = p'$ |
| $y'' = f(y, y')$ | 不显含 $x$ | 令 $y' = p$，$y'' = p\frac{dp}{dy}$ |
| 常系数齐次 | $y'' + py' + qy = 0$ | 特征方程 $\to$ 通解 |
| 常系数非齐次 | $y'' + py' + qy = f(x)$ | 齐通 + 特解（待定系数法） |
| 欧拉方程 | $x^2 y'' + pxy' + qy = f(x)$ | $x=e^t$ → 化常系数 |

**特解设法速查（$f(x) = P_m(x)e^{\lambda x}$）**：

| $\lambda$ 与特征根关系 | $k$ | $y^*$ 形式 |
|:-----------------------|:---:|:----------|
| $\lambda$ 非特征根 | 0 | $Q_m(x)e^{\lambda x}$ |
| $\lambda$ 是单重特征根 | 1 | $x Q_m(x)e^{\lambda x}$ |
| $\lambda$ 是二重特征根 | 2 | $x^2 Q_m(x)e^{\lambda x}$ |
