## 二、计算题（每小题 8 分，共 56 分）

### 1. 解：
$$\lim_{x \to 0} (1 + 4\tan^2 x)^{\cot^2 x}$$
$$= \lim_{x \to 0} \left[(1 + 4\tan^2 x)^{\frac{1}{4\tan^2 x}}\right]^{4}$$
$$= e^4 \quad \text{（6 分）}$$

### 2. 解：
方程两边关于 $x$ 求导得
$$e^y \cdot y' = -y - xy',$$
于是
$$y' = -\dfrac{y}{x + e^y}. \quad \text{（4 分）}$$

又当 $x = 0$ 时，$y = 0$，所以
$$\left. \dfrac{dy}{dx} \right|_{x=0} = 0. \quad \text{（4 分）}$$

### 3. 解：
令 $t = \sqrt{1+x}$，则 $dx = 2t \, dt$，（2 分）

$$\int \dfrac{x}{1 + \sqrt{1+x}} \, dx = \int \dfrac{t^2 - 1}{1 + t} \cdot 2t \, dt = \int 2t(t-1) \, dt$$
$$= \dfrac{2}{3}t^3 - t^2 + C = (1+x)\left(\dfrac{2}{3}\sqrt{x+1} - 1\right) + C$$
$$= \dfrac{2}{3}(1+x)^{\frac{3}{2}} - x + C \quad \text{（6 分）}$$

### 4. 解：
$$\int_{1}^{2} [x^2] \, dx = \int_{1}^{\sqrt{2}} 1 \, dx + \int_{\sqrt{2}}^{\sqrt{3}} 2 \, dx + \int_{\sqrt{3}}^{2} 3 \, dx \quad \text{（4 分）}$$
$$= (\sqrt{2} - 1) + 2(\sqrt{3} - \sqrt{2}) + 3(2 - \sqrt{3})$$
$$= 5 - \sqrt{2} - \sqrt{3} \quad \text{（4 分）}$$

### 5. 解：
$$\int_{0}^{\frac{\pi}{2}} x^2 \sin x \, dx = -\int_{0}^{\frac{\pi}{2}} x^2 \, d(\cos x)$$
$$= -\left. x^2 \cos x \right|_{0}^{\frac{\pi}{2}} + 2\int_{0}^{\frac{\pi}{2}} x \cos x \, dx \quad \text{（4 分）}$$
$$= 2\int_{0}^{\frac{\pi}{2}} x \, d(\sin x) = 2\left. x \sin x \right|_{0}^{\frac{\pi}{2}} - 2\int_{0}^{\frac{\pi}{2}} \sin x \, dx$$
$$= 2 \cdot \dfrac{\pi}{2} + 2\left. \cos x \right|_{0}^{\frac{\pi}{2}} = \pi - 2 \quad \text{（4 分）}$$

### 6. 解：
原方程可化为
$$\dfrac{dy}{dx} - \dfrac{3}{x}y = -\dfrac{x}{2}, \quad \text{（3 分）}$$

所求的通解为：
$$y = e^{\int \frac{3}{x}dx} \left( \int \left(-\dfrac{x}{2}\right) e^{-\int \frac{3}{x}dx} dx + C \right)$$
$$= e^{3\ln x} \left( \int \left(-\dfrac{x}{2}\right) e^{-3\ln x} dx + C \right) = x^3 \left( \int \left(-\dfrac{x}{2}\right) \cdot \dfrac{1}{x^3} dx + C \right)$$
$$= x^3 \left( \int \left(-\dfrac{1}{2x^2}\right) dx + C \right) = x^3 \left( \dfrac{1}{2x} + C \right)$$
$$= \dfrac{1}{2}x^2 + Cx^3. \quad \text{（5 分）}$$

### 7. 解：
由题知对应齐次方程的特征方程为 $r^2 + 4r + 3 = 0$，
解得 $r_1 = -1, \, r_2 = -3$。（2 分）

于是对应齐次方程的通解为 $y = C_1 e^{-x} + C_2 e^{-3x}$。（2 分）

因 $\lambda = -1$ 是特征根，故设非齐次方程的特解为：$Y^* = axe^{-x}$。（2 分）
把它代入所给方程，得 $a = 1$，所以 $Y^* = xe^{-x}$。

故已知方程的通解为
$$y = C_1 e^{-x} + C_2 e^{-3x} + xe^{-x}. \quad \text{（2 分）}$$

## 三、证明题（8 分）

证明：
$$F(x) = \int_{0}^{x} (x^2 - t^2) f'(t) \, dt = x^2 \int_{0}^{x} f'(t) \, dt - \int_{0}^{x} t^2 f'(t) \, dt,$$

$$F'(x) = 2x \int_{0}^{x} f'(t) \, dt + x^2 f'(x) - x^2 f'(x) = 2x \int_{0}^{x} f'(t) \, dt,$$

因为正常数 $a$ 是 $F(x)$ 的极值点，由费马引理得
$$F'(a) = 2a \int_{0}^{a} f'(t) \, dt = 0, \quad \text{（3 分）}$$

于是
$$\int_{0}^{a} f'(t) \, dt = 0 \quad (a > 0),$$
即 $f(a) - f(0) = 0$，或 $f(a) = f(0)$。

又由已知条件，$f(x)$ 有一阶连续的导数，故由罗尔定理得，至少存在一点 $c \in (0, a)$，使得 $f'(c) = 0$。（5 分）
