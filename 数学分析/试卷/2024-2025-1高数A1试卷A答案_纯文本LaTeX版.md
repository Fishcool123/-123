## 二、计算题（每小题 8 分，共 56 分）

### 1. 解：
因为
$$f(x) = \begin{cases} e^{ax}, & x \leq 0 \\ b(1-x), & x > 0 \end{cases}$$
在点 $x = 0$ 处可导必连续，所以 $b = 1$。（4 分）

又在点 $x = 0$ 处可导，所以由 $f'_-(0) = a, \, f'_+(0) = -1$，得 $a = -1$。（4 分）

### 2. 解：
定义域 $(-\infty, 0) \cup (0, +\infty)$，
$$y' = -\dfrac{x+2}{x^3}, \quad y'' = \dfrac{2(x+3)}{x^4}$$（2 分）

令 $y' = 0$，得驻点 $x_1 = -2$；
令 $y'' = 0$，得 $x_2 = -3$。（2 分）

| $x$ | $(-\infty, -3)$ | $-3$ | $(-3, -2)$ | $-2$ | $(-2, 0)$ | $0$ | $(0, +\infty)$ |
|-----|-----------------|------|------------|------|-----------|-----|----------------|
| $y'$ | $-$ | | $-$ | $0$ | $+$ | | $-$ |
| $y''$ | $-$ | $0$ | $+$ | | $+$ | | $+$ |
| $y$ | | 拐点 | | 极小值 | | | |

函数的单调增加区间为 $(-2, 0)$，单调减少区间为 $(-\infty, -2)$ 及 $(0, +\infty)$，
在 $x = -2$ 处，有极小值 $-\dfrac{1}{4}$。（2 分）

其图形的凹区间为 $(-3, 0)$ 及 $(0, +\infty)$，凸区间为 $(-\infty, -3)$。（2 分）

### 3. 解：
$$\int \dfrac{x^2 + \ln x}{x} \, dx = \int x \, dx + \int \dfrac{\ln x}{x} \, dx$$
$$= \int x \, dx + \dfrac{1}{2} \int \ln x \, d(\ln x) \quad \text{（3 分）}$$
$$= \dfrac{1}{2}x^2 + \dfrac{\ln^2 x}{2} + C \quad \text{（5 分）}$$

### 4. 解：
令 $\sqrt{2x-1} = t$，则 $x = \dfrac{t^2 + 1}{2}$，$dx = t \, dt$，（2 分）

$$\int_{\frac{1}{2}}^{1} e^{\sqrt{2x-1}} \, dx = \int_{0}^{1} t e^t \, dt = \int_{0}^{1} t \, d(e^t) \quad \text{（3 分）}$$
$$= \left. t e^t \right|_{0}^{1} - \int_{0}^{1} e^t \, dt = e - \left. e^t \right|_{0}^{1} = e - (e - 1) = 1 \quad \text{（3 分）}$$

### 5. 解：
$$\int_{0}^{\frac{\pi}{2}} \dfrac{x}{1+\cos x} \, dx = \int_{0}^{\frac{\pi}{2}} \dfrac{x}{2\cos^2 \dfrac{x}{2}} \, dx = \int_{0}^{\frac{\pi}{2}} x \, d\left(\tan \dfrac{x}{2}\right) \quad \text{（3 分）}$$

$$= \left. x \tan \dfrac{x}{2} \right|_{0}^{\frac{\pi}{2}} - \int_{0}^{\frac{\pi}{2}} \tan \dfrac{x}{2} \, dx$$
$$= \dfrac{\pi}{2} - \int_{0}^{\frac{\pi}{2}} \dfrac{\sin \dfrac{x}{2}}{\cos \dfrac{x}{2}} \, d\left(\dfrac{x}{2}\right) \quad \text{（3 分）}$$

$$= \dfrac{\pi}{2} + \left. \ln \left| \cos \dfrac{x}{2} \right| \right|_{0}^{\frac{\pi}{2}} = \dfrac{\pi}{2} + \ln \dfrac{\sqrt{2}}{2} = \dfrac{\pi}{2} - \ln \sqrt{2} \quad \text{（2 分）}$$

### 6. 解：
特征方程是 $r^2 + 4r + 4 = 0$，即 $(r + 2)^2 = 0$，故 $r_1 = r_2 = -2$。（4 分）

因此方程的通解是 $y = (C_1 + C_2 x) e^{-2x}$。（4 分）

### 7. 解：
(1) 面积
$$A = \int_{0}^{2} y \, dx = \int_{0}^{1} \sqrt{1-x^2} \, dx + \int_{1}^{2} |x^2 - 1| \, dx \quad \text{（2 分）}$$
$$= \int_{0}^{1} \sqrt{1-x^2} \, dx + \int_{1}^{2} (x^2 - 1) \, dx$$
$$= \left[ \dfrac{x}{2}\sqrt{1-x^2} + \dfrac{1}{2}\arcsin x \right]_{0}^{1} + \left[ \dfrac{1}{3}x^3 - x \right]_{1}^{2}$$
$$= \dfrac{\pi}{4} + \left( \dfrac{8}{3} - 2 \right) - \left( \dfrac{1}{3} - 1 \right) = \dfrac{\pi}{4} + 2 \quad \text{（2 分）}$$

(2) 绕 $x$ 轴旋转的体积
$$V_x = \pi \int_{0}^{2} y^2 \, dx = \pi \int_{0}^{2} (1 - x^2)^2 \, dx \quad \text{（2 分）}$$
$$= \pi \int_{0}^{2} (1 - 2x^2 + x^4) \, dx$$
$$= \pi \left[ x - \dfrac{2}{3}x^3 + \dfrac{1}{5}x^5 \right]_{0}^{2} = \pi \left( 2 - \dfrac{16}{3} + \dfrac{32}{5} \right) = \dfrac{46}{15}\pi \quad \text{（2 分）}$$

## 三、证明题（17 分）

### 1. 证明：（8 分）
令 $x = \dfrac{\pi}{2} - u$，（2 分）

$$\int_{0}^{\frac{\pi}{2}} f(\sin x) \, dx = \int_{\frac{\pi}{2}}^{0} f(\cos u) (-du)$$
$$= \int_{0}^{\frac{\pi}{2}} f(\cos u) \, du$$
$$= \int_{0}^{\frac{\pi}{2}} f(\cos x) \, dx$$

### 2. 证明：（9 分）
$f(x)$ 在 $[0,1]$ 上连续且 $f(x) < 1$，所以
$$\int_{0}^{1} f(t) \, dt < 1, \quad \text{（2 分）}$$

$$F(0) = -1 < 0, \quad F(1) = 2 - 1 - \int_{0}^{1} f(t) \, dt > 0, \quad \text{（2 分）}$$

$F(x)$ 在 $[0,1]$ 上连续，根据介值定理至少存在一点 $\xi \in (0,1)$ 使得 $F(\xi) = 0$；（2 分）

而 $F'(x) = 2 - f(x) > 0, \, x \in (0,1)$，即 $F(x)$ 单调增，所以只有一个零点。（3 分）
