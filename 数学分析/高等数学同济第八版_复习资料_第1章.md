# 第1章 函数与极限

> 期末命题权重：基础章，直接考题占比约 15%~20%，但极限计算能力贯穿全书。

---

## 1-1 映射与函数

### 核心概念/定理

- **函数两要素**：**定义域** $D_f$ + **对应法则** $f$（值域自动确定，不算基本要素）。
- **基本初等函数**（六类）：幂函数、指数函数、对数函数、三角函数、反三角函数、常量函数。
- **初等函数**：由常数和基本初等函数经过**有限次四则运算和复合运算**构成，且能**用一个式子表示**的函数。
- **邻域**：$U(a,\delta) = (a-\delta, a+\delta)$；**空心邻域**：$\mathring{U}(a,\delta) = (a-\delta, a) \cup (a, a+\delta)$。

### 核心公式

| 函数特性 | 判定 |
|:---------|:-----|
| **有界性** | $\exists M > 0,\ \forall x \in I,\ |f(x)| \le M$ |
| **奇偶性** | 奇函数 $f(-x) = -f(x)$，图像关于原点对称；偶函数 $f(-x) = f(x)$，图像关于 $y$ 轴对称 |
| **单调性** | $x_1 < x_2 \Rightarrow f(x_1) \le f(x_2)$（增）或 $f(x_1) \ge f(x_2)$（减） |
| **周期性** | $\exists T > 0,\ f(x+T) = f(x)$ |

### ⚠️ 易错点与防坑指南

- **分段函数不是看"有几个表达式"，而是看"定义域是否分段给出"**。分段函数可以是初等函数（如 $|x| = \sqrt{x^2}$），但多数分段定义函数不是初等函数。
- **定义域是命题的起点**：遇到 $f(x)$，未声明定义域时默认为**自然定义域**（使表达式有意义的全体实数）。
- **复合函数的存在条件**：$f \circ g$ 存在 $\iff$ $g$ 的值域 $\subseteq$ $f$ 的定义域。

### 🔑 典型解题套路（SOP）

**已知 $f(x)$ 表达式 + $g(x)$ 表达式，求复合函数 $f[g(x)]$：**

- Step 1：写出 $f(u)$，替换 $u = g(x)$；
- Step 2：**倒推定义域**：从 $f$ 对 $u$ 的限制 → $g(x)$ 满足的条件，解不等式得 $x$ 范围；
- Step 3：合并写出复合函数表达式 + 定义域。

## 1-2 数列的极限

### 核心概念/定理

- **数列极限的 $\varepsilon$-$N$ 定义**：$\displaystyle\lim_{n \to \infty} x_n = a \iff \forall \varepsilon > 0,\ \exists N \in \mathbb{N}^+,\ \forall n > N,\ |x_n - a| < \varepsilon$。
- **收敛数列的性质**：
  - **唯一性**：若极限存在，则极限值唯一；
  - **有界性**：收敛数列必有界（⚠️ 有界数列未必收敛）；
  - **保号性**：若 $\lim x_n = a > 0$，则 $n$ 充分大时 $x_n > 0$；
  - **迫敛性（夹逼准则）**：$y_n \le x_n \le z_n$ 且 $\lim y_n = \lim z_n = a \Rightarrow \lim x_n = a$。

### 核心公式

**单调有界准则**：单调递增（递减）且有上（下）界的数列必收敛。

**常用结论**：
- $\displaystyle\lim_{n \to \infty} \sqrt[n]{n} = 1$
- $\displaystyle\lim_{n \to \infty} \sqrt[n]{a} = 1 \ (a > 0)$
- $\displaystyle\lim_{n \to \infty} q^n = 0 \ (|q| < 1)$

### ⚠️ 易错点与防坑指南

- **极限中的"无限逼近"不等于"到达"**：$x_n$ 可以永远不等于 $a$（如 $x_n = \frac{1}{n} \neq 0$）。
- **$\varepsilon$-$N$ 语言**：$N$ 依赖于 $\varepsilon$，通常取 $N = \left[\frac{1}{\varepsilon}\right] + 1$ 之类，**先有 $\varepsilon$ 才有 $N$**。

## 1-3 函数的极限

### 核心概念/定理

- **函数极限的 $\varepsilon$-$\delta$ 定义**：$\displaystyle\lim_{x \to x_0} f(x) = A \iff \forall \varepsilon > 0,\ \exists \delta > 0,\ \forall x: 0 < |x - x_0| < \delta,\ |f(x) - A| < \varepsilon$。
- **$x \to \infty$ 时**：$\displaystyle\lim_{x \to \infty} f(x) = A \iff \forall \varepsilon > 0,\ \exists X > 0,\ \forall |x| > X,\ |f(x) - A| < \varepsilon$。
- **左右极限**：$\displaystyle\lim_{x \to x_0} f(x) = A \iff \lim_{x \to x_0^-} f(x) = \lim_{x \to x_0^+} f(x) = A$。

### ⚠️ 易错点与防坑指南

- **极限存在 $\iff$ 左右极限同时存在且相等**。这是分段函数在分段点处极限讨论的**绝对标准程序**。
- **$x \to \infty$ 包含 $x \to +\infty$ 和 $x \to -\infty$ 两种情况**：$\lim_{x\to\infty} f(x)$ 存在要求 $\lim_{x\to+\infty}$ 和 $\lim_{x\to-\infty}$ 同时存在且相等。
- **$\lim f(x) = A$ 与 $f(x_0)$ 无关**：极限只关心 $x$ 趋近 $x_0$ 过程中的趋势，$f(x_0)$ 是否有定义、取何值都不影响极限。

## 1-4 无穷小与无穷大

### 核心概念/定理

- **无穷小**：$\displaystyle\lim_{x \to x_0} f(x) = 0$，称 $f(x)$ 为 $x \to x_0$ 时的无穷小量。**⚠️ 无穷小是变量，不是"很小的数"**。
- **无穷大**：$\displaystyle\lim_{x \to x_0} f(x) = \infty$，称 $f(x)$ 为 $x \to x_0$ 时的无穷大量。**⚠️ 无穷大是变量，不是"很大的数"**。

### 核心公式

| 性质 | 内容 |
|:-----|:-----|
| 有限个无穷小的和 | 仍是无穷小 |
| 有限个无穷小的积 | 仍是无穷小 |
| 无穷小 × 有界函数 | 仍是无穷小 |
| 无穷小 ÷ 无穷小 | 不确定（需比较阶数） |
| 无穷小的倒数 | 是无穷大（条件：无穷小不恒为零） |
| 无穷大的倒数 | 是无穷小 |

### ⚠️ 易错点与防坑指南

- **无穷大 ≠ 无界**：例如 $f(x) = x \sin x$ 无界但不是无穷大（$x \to \infty$ 时不趋于无穷）。无穷大是**趋于无穷**，而无界只要**存在**趋于无穷的子列即可。
- **$0$ 是无穷小，但无穷小不一定是 $0$**。常数 $0$ 作为函数是无穷小的唯一常数特例——任何非零常数都不是无穷小。

### 🔑 典型解题套路（SOP）

**判断函数是否为 $x \to x_0$（或 $x \to \infty$）时的无穷小/无穷大：**

- Step 1：直接计算极限，若 $\lim = 0$ 则为无穷小，若 $\lim = \infty$ 则为无穷大；
- Step 2：若出现 $\infty - \infty$ / $\frac{0}{0}$ 等未定式，先变形（通分/有理化/提取公因子）再判断。

## 1-5 极限运算法则

### 核心概念/定理

设 $\lim f(x) = A$，$\lim g(x) = B$（$A, B$ 为有限数），则：

| 法则 | 公式 |
|:-----|:-----|
| 加减 | $\lim [f(x) \pm g(x)] = A \pm B$ |
| 乘法 | $\lim [f(x) \cdot g(x)] = A \cdot B$ |
| 除法 | $\lim \dfrac{f(x)}{g(x)} = \dfrac{A}{B}$（$B \neq 0$） |
| 常数因子 | $\lim [c \cdot f(x)] = c \cdot A$ |
| 乘方 | $\lim [f(x)]^n = A^n$ |

### ⚠️ 易错点与防坑指南

- **四则运算法则的前提是 $\lim f$ 和 $\lim g$ 均存在且为有限数**。一旦出现 $\infty$ 参与的运算，必须当做**未定式**另行处理。
- **"存在 + 不存在 = 不存在"**：已知 $\lim f$ 存在而 $\lim g$ 不存在，则 $\lim (f + g)$ 一定不存在（否则推出矛盾）。
- **分子分母同时除以最高次幂** 是处理 $\frac{\infty}{\infty}$ 型多项式分式的**标准第一反应**：
  $$\lim_{x \to \infty} \frac{a_m x^m + \cdots + a_0}{b_n x^n + \cdots + b_0} = \begin{cases} 0, & m < n \\ \dfrac{a_m}{b_n}, & m = n \\ \infty, & m > n \end{cases}$$

## 1-6 极限存在准则 两个重要极限

### 核心概念/定理

- **夹逼准则**（迫敛性）：若 $g(x) \le f(x) \le h(x)$ 且 $\lim g(x) = \lim h(x) = A$，则 $\lim f(x) = A$。
- **单调有界准则**：单调递增（或递减）且有界，则必收敛。

### 核心公式

**⚠️ 两大杀器——期末考试极限题的命脉：**

**重要极限 I**（$\frac{0}{0}$ 型原型）：
$$\boxed{\lim_{x \to 0} \frac{\sin x}{x} = 1}$$

**重要极限 II**（$1^\infty$ 型原型）：
$$\boxed{\lim_{x \to 0} (1 + x)^{\frac{1}{x}} = e \quad \text{或等价地} \quad \lim_{x \to \infty} \left(1 + \frac{1}{x}\right)^x = e}$$

**$1^\infty$ 型标准公式**（由重要极限 II 推广）：
$$\boxed{\lim f(x)^{g(x)} = e^{\lim \left[f(x)-1\right] g(x)} \quad \left(\text{前提:}\lim f(x) = 1,\ \lim g(x) = \infty\right)}$$

### ⚠️ 易错点与防坑指南

- **重要极限 I 必须满足框架一致**：$\displaystyle\lim_{\boxed{\triangle} \to 0} \frac{\sin\boxed{\triangle}}{\boxed{\triangle}} = 1$，框内必须**同一个趋于 0 的表达式**。
- **⚠️ 致命对比**：$\lim_{x \to 0} \frac{\sin x}{x} = 1$，但 $\lim_{x \to \infty} \frac{\sin x}{x} = 0$（无穷小 × 有界量）。看到 $\frac{\sin \square}{\square}$ 必须先看清趋向是 $0$ 还是 $\infty$，严禁无脑写 1！
- **$1^\infty$ 型必须使用 $e^{\lim \alpha\beta}$ 公式**，绝对禁止写"$\lim = 1^\infty = 1$"这种自杀式错误！也不得直接套用 $(1+u)^{1/u} \to e$ 的朴素形式来算带复杂幂的 $1^\infty$——用 $e^{\lim (f-1)g}$ 是统一且稳妥的。
- **$a^x - 1 \sim x \ln a$** 来源于重要极限 I/II 的变形，不是独立的记忆点，但必须会用。

## 1-7 无穷小的比较

### 核心概念/定理

设 $\displaystyle\lim_{x \to x_0} \alpha(x) = 0,\ \lim_{x \to x_0} \beta(x) = 0$，且 $\beta(x) \neq 0$：

| 条件 | 结论 |
|:-----|:-----|
| $\lim \dfrac{\alpha}{\beta} = 0$ | $\alpha$ 是比 $\beta$ **高阶**的无穷小，记 $\alpha = o(\beta)$ |
| $\lim \dfrac{\alpha}{\beta} = C \neq 0$ | $\alpha$ 与 $\beta$ **同阶**无穷小 |
| $\lim \dfrac{\alpha}{\beta} = 1$ | $\alpha$ 与 $\beta$ **等价**无穷小，记 $\alpha \sim \beta$ |
| $\lim \dfrac{\alpha}{\beta^k} = C \neq 0$ | $\alpha$ 是 $\beta$ 的 $k$ 阶无穷小 |

### 核心公式

**笔试必背 · 常用等价无穷小（$x \to 0$）：**

| 等价关系 | 记忆锚点 |
|:---------|:--------|
| $\sin x \sim x$ | 正弦≈弧 |
| $\tan x \sim x$ | 正切≈弧 |
| $\arcsin x \sim x$ | 反三角≈弧 |
| $\arctan x \sim x$ | 反三角≈弧 |
| $\ln(1+x) \sim x$ | 对数≈增量 |
| $e^x - 1 \sim x$ | 指数≈增量 |
| $a^x - 1 \sim x \ln a$ | 推广指数 |
| $(1+x)^\alpha - 1 \sim \alpha x$ | 二项式线性化 |
| $1 - \cos x \sim \dfrac{x^2}{2}$ | 余弦缺半平方 |
| $x - \sin x \sim \dfrac{x^3}{6}$ | 正弦一阶差 |
| $\tan x - x \sim \dfrac{x^3}{3}$ | 正切一阶差 |
| $\arcsin x - x \sim \dfrac{x^3}{6}$ | — |

> **💡 核心本质提示**：上述三阶等价无穷小（如 $x - \sin x \sim \frac{x^3}{6}$）本质上是泰勒展开的前几项。在加减法中使用它们，本质上就是在用泰勒公式。打通这两者的联系，极限计算将再无死角。

### ⚠️ 易错点与防坑指南（期末高频丢分区）

> **🔴 红色警报：等价无穷小替换只适用于乘除因子，绝不可以在加减运算中随意替换！**

- **✅ 正确做法**：$\displaystyle\lim_{x \to 0} \frac{\sin x \cdot \ln(1+x)}{x^2} = \lim_{x \to 0} \frac{x \cdot x}{x^2} = 1$
- **❌ 致命错误**：$\displaystyle\lim_{x \to 0} \frac{\sin x - \tan x}{x^3} \overset{?\neq}{=} \lim_{x \to 0} \frac{x - x}{x^3} = 0$（正确答案是 $-\frac{1}{2}$！）
- **加减中要用泰勒展开**：加减法中等阶抵消时，泰勒展开到足够高的阶是唯一正确方法。

### 🔑 典型解题套路（SOP）

**求极限的方法优先级（期末考场标准流程）：**

> $$\boxed{\text{等价无穷小替换(乘除因子)} \ \to\ \text{泰勒展开(加减场景)} \ \to\ \text{洛必达法则(含参/含振荡 — 必须谨慎)}}$$

- Step 1：识别极限类型（$\frac{0}{0}, \frac{\infty}{\infty}, 0 \cdot \infty, \infty - \infty, 1^\infty, 0^0, \infty^0$）；
- Step 2：如果是 $\frac{0}{0}$ 或 $\frac{\infty}{\infty}$ — **先对乘除因子做等价代换**，化简表达式；
- Step 3：若等价代换后仍为 $\frac{0}{0}$ 且含加减结构 — **上泰勒展开**，每项展开到首项不被抵消的阶；
- Step 4：若无有效的等价/泰勒手段，且满足洛必达条件（$\frac{0}{0}$ 或 $\frac{\infty}{\infty}$ + 导数比极限存在），再用洛必达；
- Step 5：如果是 $1^\infty$ 型 — **立即套用 $e^{\lim (f-1)g}$ 公式**，别犹豫；
- Step 6：检查结果是否合理，尤其是振荡因子场景中洛必达的失效警告。

## 1-8 函数的连续性与间断点

### 核心概念/定理

**函数在点 $x_0$ 连续的三个等价定义：**

1. $\displaystyle\lim_{\Delta x \to 0} \Delta y = 0$（增量形式）
2. $\displaystyle\lim_{x \to x_0} f(x) = f(x_0)$（极限形式）
3. $\forall \varepsilon > 0,\ \exists \delta > 0,\ \forall x : |x - x_0| < \delta,\ |f(x) - f(x_0)| < \varepsilon$（$\varepsilon$-$\delta$ 形式）

**左连续**：$\displaystyle\lim_{x \to x_0^-} f(x) = f(x_0)$；**右连续**：$\displaystyle\lim_{x \to x_0^+} f(x) = f(x_0)$。

**连续 $\iff$ 左连续且右连续**。

### 核心公式

**间断点分类（期末考试必考的知识结构树）：**

```
间断点
├── 第一类间断点（左右极限均存在）
│   ├── 可去间断点：左极限 = 右极限 ≠ f(x₀)（或f(x₀)无定义）
│   └── 跳跃间断点：左极限 ≠ 右极限
└── 第二类间断点（左右极限至少一个不存在）
    ├── 无穷间断点：至少一侧为∞
    ├── 振荡间断点：极限振荡不存在（如 sin(1/x) 在 x=0）
    └── 其他
```

### ⚠️ 易错点与防坑指南

- **可去间断点可以通过"重新定义或补充定义函数值"修复为连续点**——这是命题人爱出的判断题："可去间断点能否通过改变函数值变为连续？"→ 能。
- **跳跃间断点不可修复** — 左右极限不同，改一个点没用。
- **分段函数在分段点处的连续性必须考察左右极限**，这是铁律，省略即丢分。

## 1-9 连续函数的运算与初等函数的连续性

### 核心概念/定理

- **连续函数的和、差、积、商（分母不为零）仍连续**。
- **反函数连续性**：若 $y = f(x)$ 在区间 $I$ 上严格单调且连续，则其反函数 $x = f^{-1}(y)$ 在对应区间上**严格单调且连续**。
- **复合函数连续性**：若 $u = g(x)$ 在 $x_0$ 连续，$y = f(u)$ 在 $u_0 = g(x_0)$ 连续，则 $f \circ g$ 在 $x_0$ 连续。

### ⚠️ 关键结论

> **一切初等函数在其定义域内的每一点都是连续的。**

这一结论是极限计算的"通行证"：只要函数在 $x_0$ 处是初等函数且有定义，则
$$\lim_{x \to x_0} f(x) = f(x_0)$$
直接代入即可！

## 1-10 闭区间上连续函数的性质

### 核心概念/定理

> 以下三个定理是证明方程根存在的**绝对高频率工具**。前提条件缺一不可：**闭区间 $[a, b]$** + **连续**。

**定理 1：最大值最小值定理（最值定理）**

**前提条件**：$f(x)$ 在闭区间 $[a, b]$ 上连续。

**结论**：$f(x)$ 在 $[a, b]$ 上必能取到最大值 $M$ 和最小值 $m$，即 $\exists \xi_1, \xi_2 \in [a, b]$，使 $f(\xi_1) = m,\ f(\xi_2) = M$。

**定理 2：介值定理**

**前提条件**：$f(x)$ 在闭区间 $[a, b]$ 上连续，$\mu$ 为介于 $f(a)$ 与 $f(b)$ 之间的任意数。

**结论**：$\exists \xi \in [a, b]$，使 $f(\xi) = \mu$。

**定理 3：零点定理（根的存在定理）**

**前提条件**：$f(x)$ 在闭区间 $[a, b]$ 上连续，且 $f(a) \cdot f(b) < 0$。

**结论**：$\exists \xi \in (a, b)$，使 $f(\xi) = 0$。

### ⚠️ 易错点与防坑指南

- **最值定理的"闭区间 + 连续"两个条件缺一不可**：$f(x) = \frac{1}{x}$ 在 $(0, 1]$ 上连续但在开区间无最大值（上无界）；$f(x) = \frac{1}{x}$ 在 $[0.1, 1]$ 上满足条件则有最值。
- **零点定理只能证"存在"根，不能证唯一性**。唯一性需要额外结合单调性。
- **介值定理 $f(a)$ 和 $f(b)$ 之间的一切值都能取遍** — 闭区间连续函数的像也是闭区间 $[m, M]$。

### 🔑 典型解题套路（SOP）

**证明方程 $F(x) = 0$ 在区间内至少有一根（零点定理标准流程）：**

- Step 1：构造辅助函数 $f(x) = F(x)$，确认 $f(x)$ 在 $[a, b]$ 上连续；
- Step 2：计算端点值 $f(a)$ 和 $f(b)$；
- Step 3：验证 $f(a) \cdot f(b) < 0$（异号）；
- Step 4：由零点定理，$\exists \xi \in (a, b)$ 使 $f(\xi) = 0$，即 $F(\xi) = 0$ 有根。

- Step 5：若还需证唯一性，追加证明 $f(x)$ 在 $(a, b)$ 上严格单调（$f'(x) > 0$ 或 $f'(x) < 0$）。（**注：此步骤需结合第三章"导数与单调性"的知识，在第一章复习时先了解思路即可**。）

## 📋 第一章速查：常用麦克劳林展开式（$x \to 0$）

> 以下展开式是极限计算的终极武器，含皮亚诺余项 $o(x^n)$。期末考试极限题逼到墙角且等价代换无法进场时，**果断展开**。

| 函数 | 麦克劳林展开式 |
|:-----|:---------------|
| $e^x$ | $1 + x + \dfrac{x^2}{2!} + \dfrac{x^3}{3!} + \cdots + \dfrac{x^n}{n!} + o(x^n)$ |
| $\sin x$ | $x - \dfrac{x^3}{3!} + \dfrac{x^5}{5!} - \cdots + (-1)^n \dfrac{x^{2n+1}}{(2n+1)!} + o(x^{2n+2})$ |
| $\cos x$ | $1 - \dfrac{x^2}{2!} + \dfrac{x^4}{4!} - \cdots + (-1)^n \dfrac{x^{2n}}{(2n)!} + o(x^{2n+1})$ |
| $\ln(1+x)$ | $x - \dfrac{x^2}{2} + \dfrac{x^3}{3} - \cdots + (-1)^{n-1} \dfrac{x^n}{n} + o(x^n)$ |
| $(1+x)^\alpha$ | $1 + \alpha x + \dfrac{\alpha(\alpha-1)}{2!}x^2 + \cdots + \dfrac{\alpha(\alpha-1)\cdots(\alpha-n+1)}{n!}x^n + o(x^n)$ |
| $\tan x$ | $x + \dfrac{x^3}{3} + \dfrac{2x^5}{15} + o(x^5)$ |
| $\arctan x$ | $x - \dfrac{x^3}{3} + \dfrac{x^5}{5} + o(x^5)$ |
| $\arcsin x$ | $x + \dfrac{x^3}{6} + o(x^3)$ |

**常用特例（从 $(1+x)^\alpha$ 派生）：**
- $\dfrac{1}{1+x} = 1 - x + x^2 - x^3 + \cdots$（$\alpha = -1$）
- $\sqrt{1+x} = 1 + \dfrac{x}{2} - \dfrac{x^2}{8} + \cdots$（$\alpha = \frac{1}{2}$）
