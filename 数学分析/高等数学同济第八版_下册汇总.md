## 第8章 向量代数与空间解析几何

### 8-1 节次概览

空间直角坐标系与向量线性运算 → 向量的模/方向角/投影与数量积 → 向量积（叉积）→ 混合积 → 空间平面及其方程 → 空间直线及其方程 → 二次曲面

### 8-2 核心公式

**向量运算**：

| 运算 | 公式 | 应用 |
|:-----|:-----|:-----|
| 点积 | $\vec{a}\cdot\vec{b} = a_xb_x + a_yb_y + a_zb_z = \|\vec{a}\|\|\vec{b}\|\cos\theta$ | 判垂直、求夹角、求投影 |
| 叉积 | $\vec{a}\times\vec{b} = \begin{vmatrix}\vec{i}&\vec{j}&\vec{k}\\a_x&a_y&a_z\\b_x&b_y&b_z\end{vmatrix}$ | 判平行、求法向量、计算面积 |
| 混合积 | $(\vec{a}\times\vec{b})\cdot\vec{c} = \begin{vmatrix}a_x&a_y&a_z\\b_x&b_y&b_z\\c_x&c_y&c_z\end{vmatrix}$ | 判共面、算体积 |

**平面与直线**：

| 对象 | 关键公式 |
|:-----|:---------|
| 平面方程 | $Ax+By+Cz+D=0$，法向量 $\vec{n}=(A,B,C)$ |
| 直线方程 | $\frac{x-x_0}{m}=\frac{y-y_0}{n}=\frac{z-z_0}{p}$，方向向量 $\vec{s}=(m,n,p)$ |
| 点到平面距 | $d = \frac{\|Ax_0+By_0+Cz_0+D\|}{\sqrt{A^2+B^2+C^2}}$ |
| 线面夹角 | $\sin\theta = \frac{\|\vec{s}\cdot\vec{n}\|}{\|\vec{s}\|\|\vec{n}\|}$ ⚠️ 是 $\sin$ 不是 $\cos$ |
| 异面直线距离 | $d = \frac{\|(\vec{s}_1\times\vec{s}_2)\cdot\overrightarrow{M_1M_2}\|}{\|\vec{s}_1\times\vec{s}_2\|}$ |
| 四面体体积 | $V = \frac{1}{6}\|(\vec{a}\times\vec{b})\cdot\vec{c}\|$ ⚠️ 系数 $1/6$ |

**常见二次曲面**：
$$\begin{aligned}
\text{椭球面}&: \frac{x^2}{a^2}+\frac{y^2}{b^2}+\frac{z^2}{c^2}=1 \\
\text{单叶双曲面}&: \frac{x^2}{a^2}+\frac{y^2}{b^2}-\frac{z^2}{c^2}=1 \\
\text{双叶双曲面}&: \frac{x^2}{a^2}+\frac{y^2}{b^2}-\frac{z^2}{c^2}=-1 \\
\text{椭圆抛物面}&: z = \frac{x^2}{a^2}+\frac{y^2}{b^2} \\
\text{双曲抛物面(马鞍面)}&: z = \frac{x^2}{a^2}-\frac{y^2}{b^2}
\end{aligned}$$

### 8-3 ⚠️ 高频易错

1. **叉积不满足交换律**：$\vec{a}\times\vec{b} = -\vec{b}\times\vec{a}$
2. **线面夹角是 $\sin\theta$**，不是 $\cos\theta$（与线线夹角不同）
3. **四面体体积系数是 $1/6$**：经常被漏掉
4. **$\vec{a}\perp\vec{b} \iff \vec{a}\cdot\vec{b}=0$**；**$\vec{a}\parallel\vec{b} \iff \vec{a}\times\vec{b}=\vec{0}$**；**共面 $\iff$ 混合积 $=0$**

### 8-4 🔑 核心套路

**求平面方程**：找法向量 $\vec{n}$ + 一点 $P_0$ → 点法式
**求直线方程**：找方向向量 $\vec{s}$ + 一点 $P_0$ → 点向式
**求二次曲面截口**：用 $z=k$ 等平面截，得曲线类型

## 第9章 多元函数微分法及其应用

### 9-1 节次概览

基本概念 → 偏导数 → 全微分 → 链式法则（多元复合求导）→ 隐函数求导 → 方向导数与梯度 → 极值 → 切平面与法线

### 9-2 核心公式

**全微分**：
$$\boxed{dz = \frac{\partial z}{\partial x}dx + \frac{\partial z}{\partial y}dy}$$

**链式法则**（$z=f(u,v)$，$u=u(x,y)$，$v=v(x,y)$）：
$$\frac{\partial z}{\partial x} = \frac{\partial z}{\partial u}\frac{\partial u}{\partial x} + \frac{\partial z}{\partial v}\frac{\partial v}{\partial x}$$

> ⚠️ 二阶偏导：$f_1'$ 仍是复合函数，须再次链式法则展开

**隐函数求导**：
- $F(x,y)=0$ → $\displaystyle\frac{dy}{dx} = -\frac{F_x}{F_y}$ ⚠️ 别忘了负号
- $F(x,y,z)=0$ → $\displaystyle\frac{\partial z}{\partial x} = -\frac{F_x}{F_z}$，$\frac{\partial z}{\partial y} = -\frac{F_y}{F_z}$

**隐函数组（雅可比）**：
$$J = \frac{\partial(F,G)}{\partial(u,v)} = \begin{vmatrix}F_u&F_v\\G_u&G_v\end{vmatrix},\quad \frac{\partial u}{\partial x} = -\frac{1}{J}\frac{\partial(F,G)}{\partial(x,v)}$$

**方向导数与梯度**：

| 公式 | 说明 |
|:-----|:-----|
| $D_{\vec{l}}f = f_x\cos\alpha + f_y\cos\beta = \nabla f\cdot\vec{l}_0$ | ⚠️ $\vec{l}$ 必须单位化 |
| $\nabla f = (f_x, f_y)$ | 梯度，方向导数最大方向 |

**极值判别（$A=f_{xx},\ B=f_{xy},\ C=f_{yy}$）**：
$$\boxed{\Delta = AC-B^2}$$

| 条件 | 结论 |
|:-----|:-----|
| $\Delta>0,\ A>0$ | 极小值 |
| $\Delta>0,\ A<0$ | 极大值 |
| $\Delta<0$ | 不是极值（鞍点） |
| $\Delta=0$ | 判别法失效 |

> 📖 本书用 $\Delta=AC-B^2$（$\Delta>0$ 有极值）。若课堂用 $\Delta=B^2-AC$，结论反向。

**切平面与法线**：

| 曲面类型 | 法向量 | 切平面方程 |
|:---------|:------|:----------|
| $F(x,y,z)=0$ | $\vec{n}=(F_x,F_y,F_z)$ | $F_x(X-x_0)+F_y(Y-y_0)+F_z(Z-z_0)=0$ |
| $z=f(x,y)$ | $\vec{n}=(f_x,f_y,-1)$ ⚠️ | $z-z_0=f_x(x-x_0)+f_y(y-y_0)$ |

### 9-3 ⚠️ 高频易错

1. **链式法则二阶偏导**：$f_1'$ 仍是复合函数，必须再次展开
2. **方向导数 $\vec{l}$ 必须单位化**：不单位化直接除
3. **隐函数求导的负号**：$\frac{dy}{dx} = -\frac{F_x}{F_y}$，忘写负号=零分
4. **可微 ⇒ 连续 + 偏导存在**，但反向不成立
5. **曲面 $z=f(x,y)$ 的法向量第三个分量是 $-1$**，不是 $+1$
6. **条件极值用拉格朗日乘数法**：应用题驻点唯一 → 直接判最值，无需 Hessian

### 9-4 🔑 核心套路

**复合函数二阶偏导**：先求一阶偏导 → 对一阶导再次链式展开 → 代入化简
**极值应用题**：构造拉格朗日函数 $\to$ 解驻点方程组 $\to$ 消去 $\lambda$ → 若唯一驻点直接得最值
**切平面求解**：求法向量 $\to$ 代入点法式

## 第10章 重积分

### 10-1 节次概览

二重积分概念与性质 → 直角坐标计算（X型/Y型）→ 极坐标计算 → 三重积分概念 → 柱坐标计算 → 球坐标计算

### 10-2 核心公式

**二重积分坐标计算**：

| 类型 | 积分次序 | 适用场景 |
|:-----|:---------|:---------|
| X型 | $\iint_D f d\sigma = \int_a^b dx\int_{y_1(x)}^{y_2(x)} f\,dy$ | 区域上下边界好写 |
| Y型 | $\iint_D f d\sigma = \int_c^d dy\int_{x_1(y)}^{x_2(y)} f\,dx$ | 区域左右边界好写 |
| 极坐标 | $\iint_D f d\sigma = \int_\alpha^\beta d\theta\int_{r_1(\theta)}^{r_2(\theta)} f\cdot r\,dr$ | 圆/扇形区域 |

**三重积分坐标计算**：

| 坐标系 | 微元 | ⚠️ 危险性 |
|:------|:-----|:----------|
| 直角 | $dV = dxdydz$ | — |
| 柱坐标 | $dV = r\,drd\theta dz$ | 漏 $r$ → 全错 |
| 球坐标 | $dV = r^2\sin\varphi\,drd\varphi d\theta$ | 漏 $r^2\sin\varphi$ → 全错 |

**坐标变换关系**：
- 极坐标：$x=r\cos\theta,\ y=r\sin\theta,\ d\sigma = r\,drd\theta$
- 柱坐标：$x=r\cos\theta,\ y=r\sin\theta,\ z=z,\ dV = r\,drd\theta dz$
- 球坐标：$x=r\sin\varphi\cos\theta,\ y=r\sin\varphi\sin\theta,\ z=r\cos\varphi,\ dV = r^2\sin\varphi\,drd\varphi d\theta$

> ⚠️ 球坐标 $\varphi$ 范围：$[0,\pi]$（不是 $[-\pi/2,\pi/2]$）

**对称性（同定积分偶倍奇零推广）**：

| 区域对称 | 被积函数奇偶 | 结果 |
|:---------|:------------|:-----|
| $D$ 关于 $x$ 轴对称 | $f(x,-y)=-f(x,y)$ | $\iint_D = 0$ |
| $D$ 关于 $y$ 轴对称 | $f(-x,y)=-f(x,y)$ | $\iint_D = 0$ |
| $\Omega$ 关于 $xOy$ 对称 | $f(x,y,-z)=-f(x,y,z)$ | $\iiint_\Omega = 0$ |

### 10-3 ⚠️ 高频易错

1. **极坐标/柱坐标漏写 $r$**：$d\sigma = r\,drd\theta$，漏 $r$ = 全错
2. **球坐标漏写 $r^2\sin\varphi$**：这绝对是期末最高频完全丢分点
3. **球坐标 $\varphi$ 范围是 $[0,\pi]$**：很多人错写成 $[-\pi/2,\pi/2]$
4. **交换积分次序必须重画积分区域**：先画图再换序，不能凭感觉
5. **三重积分先二后一 vs 先一后二**：截面面积好求时用"先一后二"（先对 $z$ 积）

### 10-4 🔑 核心套路

**二重积分计算流程**：画区域 $D$ → 选坐标系（直角/极坐标）→ 定积分次序 → 定限 → 逐层积分
**三重积分计算流程**：画区域 $\Omega$ → 选坐标系（直角/柱/球坐标）→ 确定微元 → 定限 → 逐层积分
**坐标变换通用法则**：$x=x(u,v)$，$y=y(u,v)$ → 雅可比 $J = \frac{\partial(x,y)}{\partial(u,v)} = \begin{vmatrix}x_u & x_v \\ y_u & y_v\end{vmatrix}$，$\iint_D f(x,y)dxdy = \iint_{D'} f(x(u,v),y(u,v))\cdot|J|\,dudv$

## 第11章 曲线积分与曲面积分

### 11-1 节次概览

对弧长的曲线积分 → 对坐标的曲线积分 → 格林公式 → 对面积的曲面积分 → 对坐标的曲面积分 → 高斯公式 → 斯托克斯公式

### 11-2 核心公式

**三大公式 —— 全体期末目标90+必须掌握**：

| 公式 | 表达式 | 方向口诀 |
|:-----|:-------|:--------|
| **格林** | $\displaystyle\oint_L Pdx+Qdy = \iint_D\left(\frac{\partial Q}{\partial x}-\frac{\partial P}{\partial y}\right)d\sigma$ | **逆正顺负** |
| **高斯** | $\displaystyle\iint_\Sigma Pdydz+Qdzdx+Rdxdy = \iiint_\Omega\left(\frac{\partial P}{\partial x}+\frac{\partial Q}{\partial y}+\frac{\partial R}{\partial z}\right)dV$ | **外正内负** |
| **斯托克斯** | $\displaystyle\oint_\Gamma Pdx+Qdy+Rdz = \iint_\Sigma\begin{vmatrix}dydz&dzdx&dxdy\\\partial_x&\partial_y&\partial_z\\P&Q&R\end{vmatrix}$ | **右手定则** |

**第一类曲线积分（对弧长）**：
$$\int_L f(x,y)ds = \int_\alpha^\beta f[x(t),y(t)]\sqrt{x'^2+y'^2}\,dt$$
- $ds>0$，积分与方向无关

**第二类曲线积分（对坐标）**：
$$\int_L Pdx+Qdy = \int_\alpha^\beta [P\cdot x'(t)+Q\cdot y'(t)]dt$$
- 与方向有关：$\int_{L_{AB}} = -\int_{L_{BA}}$

**第一类曲面积分（对面积）**：
$$\iint_\Sigma f(x,y,z)dS = \iint_{D_{xy}} f[x,y,z(x,y)]\sqrt{1+z_x^2+z_y^2}\,dxdy$$

**第二类曲面积分（对坐标）**：
- 与侧有关，封闭曲面取外侧为正

**路径无关条件（格林公式配套）**：
$$\frac{\partial Q}{\partial x} = \frac{\partial P}{\partial y} \ \text{(单连通区域)}$$

**全微分求原函数**：$u(x,y)=\int_{x_0}^x P(x,y_0)dx + \int_{y_0}^y Q(x,y)dy$

### 11-3 ⚠️ 高频易错

1. **第一类曲线积分与方向无关，第二类与方向有关**：搞混这两类是扣分重灾区
2. **格林公式补线方向**：补线必须与原曲线构成区域正向（逆时针），补线不能穿奇点
3. **高斯公式必须是封闭曲面**：不封闭先补面，补的面方向必须与整体外侧一致
4. **斯托克斯公式取右手定则**：右手四指沿 $\Gamma$ 正向，拇指指向 $\Sigma$ 的法向
5. **路径无关条件仅适用于单连通区域**
6. **⚠️ 致命陷阱**：第二类曲面积分化为二重积分时，曲面投影有方向性（上侧取正、下侧取负、前侧取正、后侧取负、右侧取正、左侧取负）

### 11-4 🔑 核心套路

**曲线积分计算流程**：判断类型（对弧长/对坐标）→ 选择方法（直接积分/格林公式/路径无关）
**曲面积分计算流程**：判断类型 → 若封闭 → 高斯公式；若不封闭 → 补面+高斯公式
**全微分方程 $\int Pdx+Qdy$ 原函数求法**：用折线积分（水平走+竖直走）

## 第12章 无穷级数

### 12-1 节次概览

常数项级数的概念和性质 → 正项级数审敛法 → 交错级数（莱布尼茨）→ 任意项级数（绝对/条件收敛）→ 幂级数 → 函数展开为幂级数 → 傅里叶级数

### 12-2 核心公式

**常数项级数审敛法优先级**：
$$\boxed{\text{通项→0验证} \ \to\ \text{比值/根值审敛法} \ \to\ \text{比较审敛法(p级数标尺)}}$$

**基准级数**：
- $p$ 级数 $\sum\frac{1}{n^p}$：$p>1$ 收，$p\le1$ 发
- 等比级数 $\sum aq^{n-1}$：$|q|<1$ 收，$|q|\ge1$ 发
- $\sum\frac{1}{n\ln n}$ 发散（积分判别法）

**主要审敛法**：

| 判别法 | 公式 | 判断 |
|:------|:-----|:-----|
| 比值 | $\rho = \lim\left\|\frac{u_{n+1}}{u_n}\right\|$ | $\rho<1$ 收，$\rho>1$ 发，$\rho=1$ 失效 |
| 根值 | $\rho = \lim\sqrt[n]{\|u_n\|}$ | 同上 |
| 莱布尼茨 | 交错 $\sum(-1)^{n-1}u_n$ | $u_n\downarrow 0$ ⇒ 收敛 ⚠️ 两条件缺一不可 |
| 积分 | $\sum f(n)$ vs $\int_1^\infty f(x)dx$ | 同敛散 |

**幂级数**：
$$\boxed{R = \lim_{n\to\infty}\left|\frac{a_n}{a_{n+1}}\right|}$$

> ⚠️ $x=\pm R$ 端点必须单独判断。求导/积分不改变收敛半径 $R$，但端点可能变。

**和函数套路**：分子含 $n$ → 先积分再求导；分母含 $n$ → 先求导再积分。⚠️ 注意 $S(0)=a_0$

**傅里叶级数（周期 $2\pi$）**⚠️：
$$f(x) \sim \frac{a_0}{2} + \sum_{n=1}^{\infty}(a_n\cos nx + b_n\sin nx)$$
$$a_n = \frac{1}{\pi}\int_{-\pi}^{\pi} f(x)\cos nx\,dx,\quad b_n = \frac{1}{\pi}\int_{-\pi}^{\pi} f(x)\sin nx\,dx$$

| 关键点 | 说明 |
|:-------|:-----|
| 常数项是 $\frac{a_0}{2}$ | ⚠️ 不是 $a_0$！ |
| 端点收敛 | $x=\pm\pi$ 收敛到 $\frac{f(-\pi^+)+f(\pi^-)}{2}$ |
| 奇偶延拓 | 奇函数 $\to a_n=0$；偶函数 $\to b_n=0$（计算量减半） |
| 周期 $2l$ | $a_0 = \frac{1}{l}\int_{-l}^l f(x)dx$，$a_n = \frac{1}{l}\int_{-l}^l f(x)\cos\frac{n\pi x}{l}dx$，$b_n = \frac{1}{l}\int_{-l}^l f(x)\sin\frac{n\pi x}{l}dx$（⚠️ 分母 $l$ 不是 $\pi$） |

**常见幂级数和**：
$$\sum_{n=0}^{\infty}x^n=\frac{1}{1-x}\ (|x|<1),\quad \sum_{n=1}^{\infty}\frac{x^n}{n}=-\ln(1-x)\ (|x|<1)$$
$$\sum_{n=0}^{\infty}\frac{x^n}{n!}=e^x,\quad \sum_{n=0}^{\infty}(-1)^n\frac{x^{2n+1}}{(2n+1)!}=\sin x$$

**从已知和函数反查展开式（函数→级数方向）**：
- $e^x = \sum_{n=0}^{\infty}\frac{x^n}{n!}$；$\sin x = \sum_{n=0}^{\infty}(-1)^n\frac{x^{2n+1}}{(2n+1)!}$；$\cos x = \sum_{n=0}^{\infty}(-1)^n\frac{x^{2n}}{(2n)!}$
- $\ln(1+x) = \sum_{n=1}^{\infty}(-1)^{n-1}\frac{x^n}{n}\ (|x|<1)$；$\arctan x = \sum_{n=0}^{\infty}(-1)^n\frac{x^{2n+1}}{2n+1}\ (|x|\le1)$

### 12-3 ⚠️ 高频易错

1. **$\lim u_n=0$ 不保证收敛**，但 $\lim u_n\neq0$ 一定发散（第一反应操作）
2. **比值/根值审敛法失效（$\rho=1$）时**，换比较审敛法或积分判别法
3. **幂级数端点 $x=\pm R$ 必须单独判断**：分别代入检验
4. **傅里叶常数项是 $\frac{a_0}{2}$**：不是 $a_0$
5. **傅里叶周期 $2l$ 积分分母是 $l$**：不是 $\pi$
6. **绝对收敛 ⇒ 条件收敛 ⇒ 收敛**，但反向都不成立

### 12-4 🔑 核心套路

**幂级数和函数**：
- 构造函数：分子含 $n$ → $\int_0^x S(t)dt$ 消 $n$；分母含 $n$ → $S'(x)$ 消 $n$
- 用已知和函数 $\sum x^n = \frac{1}{1-x}$ 套用
- ⚠️ 注意 $S(0)$ 的取值，且在端点单独验证

**函数展开为幂级数**：
- 直接法：套麦克劳林级数公式
- 间接法（更常用）：用已知展开式 + 变量代换 + 四则运算 + 逐项积分/求导

**傅里叶级数做题流程**：
1. 判断周期 $2l$，确定系数积分区间 $[-l,l]$
2. 判断奇偶性 → 简化计算（奇函数 $a_n=0$，偶函数 $b_n=0$）
